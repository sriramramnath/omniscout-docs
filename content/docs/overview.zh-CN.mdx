OmniScout 是一个自包含的**终端原生网页接口**：AI agent 的本地浏览器大脑。它搜索网页、提取结构化数据、控制真实浏览器、自动化桌面应用并记住一切 — 全程不离开你的笔记本。

## 各部分如何协同

- **CLI** — 你（或你的 agent）键入的 `omniscout` 命令。每个命令都会说 JSON。
- **Daemon** — `127.0.0.1:7720` 上的常驻后台进程，让浏览器保持热启动，操作亚秒级完成。
- **后端** — Patchright（默认，隔离 Chromium）或驱动已有浏览器的扩展（使用真实登录态）。

完整图景见[工作原理](/docs/overview)：`@eN` ref、会话、profile、操作历史与事件流。

## 安装

```bash
pip install omniscout
omniscout install --skill
```

完整配置 — 浏览器、daemon、模型 — 见[安装](/docs/installation)。5 分钟 tour 见[快速上手](/docs/quickstart)。

## 设计原则

- **本地优先** — 无云端账号、API key 与托管服务。状态、embedding 与记忆都留在本机；唯一的出站流量是你运行的搜索与抓取的 URL。
- **Agent 就绪** — 处处 `--json`、稳定的 `@eN` 元素 ref、可记录的操作历史（含 trace/replay），以及 Claude Code、Cursor、Codex 与 Gemini CLI 的技能文件。
- **真实浏览器** — 你的 Chromium、你的 cookie、你的扩展。用 profile 登录一次，永久复用。

## 使用

```bash
# Start the daemon (once)
omniscout daemon start

# Search the web
omniscout answer "what is the capital of france"

# Extract content from a URL
omniscout extract https://example.com

# Control a browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research a topic
omniscout research "AI agents in 2026"

# Build a knowledge graph
omniscout graph "Cursor"
```
