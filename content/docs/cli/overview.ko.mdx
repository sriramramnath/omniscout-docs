OmniScout는 AI 에이전트에게 웹 검색, 콘텐츠 추출, 브라우저 제어, 데스크톱 작업 자동화 기능을 제공합니다 — 모두 로컬에서 실행되며 클라우드가 필요 없습니다.

## 설치

```bash
pip install omniscout
omniscout install --skill
```

## 사용법

```bash
# 데몬 시작 (한 번만)
omniscout daemon start

# 웹 검색
omniscout answer "what is the capital of france"

# URL에서 콘텐츠 추출
omniscout extract https://example.com

# 브라우저 제어
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# 주제 리서치
omniscout research "AI agents in 2026"

# 지식 그래프 구축
omniscout graph "Cursor"
```

## 할 수 있는 일

| 명령어 | 설명 |
|---------|--------------|
| `search` | 선택적 시맨틱 리랭크가 적용된 웹 검색 |
| `answer` | 인용이 포함된 직접 Q&A (`search`보다 권장) |
| `extract` | URL을 가져와 깔끔한 Markdown 반환 |
| `research` | 다단계: 검색 → 크롤 → 추출 → 요약 |
| `graph` | 구조화된 지식 그래프 구축 |
| `browser` | 브라우저 제어 (이동, 클릭, 입력, 스크린샷) |
| `computer` | 데스크톱 자동화 (macOS) |
| `remember` | 나중에 다시 보기 위해 브라우저 메모리에 URL 저장 |
| `install` | 최초 설정 |
| `daemon` | 백그라운드 서비스 관리 |
