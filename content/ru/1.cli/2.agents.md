OmniScout создан для управления ИИ-агентами. Вот как его настроить.

## 1. Установка

```bash
pip install omniscout
omniscout install --skill
```

Флаг `--skill` копирует инструкции в каталог навыков вашего агента:

| Агент | Расположение |
|---|---|
| Claude Code | `~/.claude/skills/scout/SKILL.md` |
| Cursor | `~/.cursor/skills-cursor/scout/SKILL.md` |
| Codex | `~/.codex/skills/scout/SKILL.md` |

Агент подхватит их автоматически при следующей сессии.

## 2. Запуск демона

```bash
omniscout daemon start
```

## 3. Готовый промпт

### Исследование вопроса

```text
Use OmniScout to research "state of open-source browser agents in 2026" and summarize the top 5 passages with their source URLs.
```

### Навигация и клик

```text
Open https://news.ycombinator.com using OmniScout, snapshot interactive elements, click the top story, and screenshot the result to /tmp/hn-top.png.
```

### Одноразовый вход и повторное использование

```text
Run `omniscout browser login https://github.com --profile work`, pause for me to authenticate, then screenshot my notifications page with that profile.
```

### Построение графа знаний

```text
Build a knowledge graph for "Cursor" with OmniScout. Run `omniscout graph "Cursor" --json --data`, show the tree, and cite sources.
```

### Заполнение формы

```text
Use OmniScout to open https://duckduckgo.com, fill the search box with "local-first AI agents", press Enter, wait for results, and list the top 5 results.
```

### Захват сетевого трафика

```text
Open the Vercel pricing page with OmniScout, capture network traffic while scrolling, then list requests matching stripe|payment|checkout.
```

## Советы для агентов

- Установите `OMNISCOUT_JSON=1` в начале для структурированного вывода
- Используйте `omniscout browser snapshot --refs-only` для поиска элементов, затем кликайте по `@eN`-ссылке
- Повторно делайте snapshot после каждого `navigate` — ссылки устаревают
- Закрывайте сессии командой `omniscout browser close --all` по завершении
