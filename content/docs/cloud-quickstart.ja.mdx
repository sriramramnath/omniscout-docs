OmniScout Cloudはホスト型APIです：所有インデックス上の意味検索、根拠付き回答、Fly Sprite上のリモートブラウザ／コンピューターセッションです。ローカルCLIは変わりません — Cloudは追加分です。

## 1. APIキーを取得します

1. [api.omniscout.xyz](https://api.omniscout.xyz)でサインインします。
2. **Dashboard → API Keys** → **Create key**に進みます。値をコピーします — `os_live_`で始まり、初回のみ表示されます。
3. エクスポートします：

```bash
export OMNISCOUT_API_KEY=os_live_YOUR_KEY
export OMNISCOUT_BASE_URL=https://api.omniscout.xyz
```

キーの仕組みと2つ目の資格情報（セッションシークレット）は[認証](/docs/authentication)をご覧ください。

## 2. 初回検索

```bash
curl -X POST $OMNISCOUT_BASE_URL/v0/search \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "rust async runtimes", "limit": 5}'
```

`url`、`title`、`snippet`、`score`、`rank`付きのランク済みヒットと、サポート用の`request_id`が返ります。[エンドポイント](/docs/endpoints#post-v0search)をご覧ください。

## 3. 初回回答

```bash
curl -X POST $OMNISCOUT_BASE_URL/v0/answer \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "What is the latest stable Rust version?"}'
```

`sources`と`confidence`付きの`answer`が返ります — 根拠が薄い場合はanswerがnullの`status: insufficient_information`になります。[エンドポイント](/docs/endpoints#post-v0answer)をご覧ください。

## 4. 初回ブラウザセッション

セッションはCLIと同じdaemonプリミティブをリモートSprite上で実行します。ライフサイクル：**作成 → ポーリング → 操作 → 破棄**です。

```bash
# Create (API key only) — save session_id AND session_secret
CREATE=$(curl -sS -X POST $OMNISCOUT_BASE_URL/v0/sessions \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"computer"}')

SESSION_ID=$(echo "$CREATE" | jq -r .session_id)
SESSION_SECRET=$(echo "$CREATE" | jq -r .session_secret)

# Poll until ready
curl -sS $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" | jq .status

# Act (API key + session secret)
curl -sS -X POST $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID/actions \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "x-session-secret: $SESSION_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"action":"navigate","args":{"url":"https://example.com"}}'

# Destroy (API key only)
curl -sS -X DELETE $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY"
```

種類：`"browser"`は軽量なブラウザ専用Sprite、`"computer"`は統合型（1つのセッションIDでブラウザ＋デスクトップ）です。セッションは非アクティブで期限切れになります（デフォルト30分、最大2時間） — コマンドのたびに延長されます。

SDK派の方は同じ流れのPython・TypeScript版を[SDK](/docs/sdks)でご覧ください。

## 5. 使用量を確認します

```bash
curl -sS $OMNISCOUT_BASE_URL/v0/usage \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" | jq .
```

課金は従量制のみです（インフラ原価 × 1.30） — [使用量と課金](/docs/billing)をご覧ください。
