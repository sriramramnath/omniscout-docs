Это руководство проведёт вас от нуля до рабочей автоматизации браузера примерно за пять минут. Предполагается, что вы уже выполнили [Установку](/docs/cli/installation).

## 1. Запустите daemon

```bash
omniscout daemon start
```

## 2. Получите ответ из веба

`answer` — самый быстрый путь к факту — ищет, локально реранжирует и синтезирует ответ с источниками:

```bash
omniscout answer "what is the capital of france"
```

Нужны только ранжированные ссылки? Используйте `search`:

```bash
omniscout search "local-first AI agents" --limit 5
```

См. [Поиск и ответы](/docs/cli/search) про источники, режимы глубины и движки ответов.

## 3. Извлеките страницу

`extract` превращает любой URL в чистый Markdown — без браузера:

```bash
omniscout extract https://example.com
```

Нужны конкретные поля в JSON вместо Markdown? См. [Извлечение](/docs/cli/extraction).

## 4. Управляйте браузером

Четыре команды покрывают большую часть работы с браузером: открыть страницу, получить её интерактивные элементы, действовать по `@eN` ref и сделать скриншот результата:

```bash
omniscout browser navigate https://news.ycombinator.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/hn.png
```

Ключевое правило: **snapshot возвращает `@eN` refs, и каждое действие нацелено на ref.** Делайте повторный snapshot после каждой навигации — refs устаревают при изменении страницы. См. [Автоматизация браузера](/docs/cli/browser) для полного словаря действий.

## 5. Сделайте вывод машиночитаемым

Каждая команда поддерживает `--json`, который агентам следует использовать всегда:

```bash
omniscout --json answer "What is local-first software?"
export OMNISCOUT_JSON=1   # same effect for every command
```

## 6. Очистка

```bash
omniscout browser close --all
```

## Шпаргалка

```bash
omniscout daemon start                              # once per machine
omniscout answer "..."                              # Q&A with citations
omniscout extract https://example.com               # page → Markdown
omniscout browser navigate <url>                    # open a page
omniscout browser snapshot --refs-only              # list @eN refs
omniscout browser click '@e3'                       # act on a ref
omniscout browser screenshot --out /tmp/out.png     # capture state
omniscout browser close --all                       # clean up
```
