브라우저 memory는 방문한 페이지와 작성한 메모에 대한 로컬 벡터 인덱스입니다. 지금 저장하고 나중에 의미 기반으로 떠올리세요 — LLM 호출은 없습니다.

## 페이지 기억하기

```bash
omniscout remember https://example.com/blog/post
```

`remember`는 URL을 방문하고 콘텐츠를 추출해 `memory.sqlite`에 저장합니다. 나중에 `memory`로 검색하세요:

```bash
omniscout memory "neural networks in production"
```

`memory`는 저장된 페이지를 쿼리와의 의미 유사도로 랭크하므로, 표현이 달라도 맞습니다 — 정확한 제목이나 URL이 필요 없습니다.

## 내 memory를 먼저 검색

`search` 명령어는 웹 대신 memory를 대상으로 할 수 있습니다:

```bash
omniscout search "query" --source memory
```

에이전트에서 유용합니다: 새로 웹 검색에 시간을 쓰기 전에 이미 본 것을(`--source memory`) 먼저 확인하세요.

## 코퍼스 관리

`memory`는 단순 조회가 아니라 명령어 그룹입니다:

```bash
omniscout memory "query"     # semantic search over remembered pages
omniscout memory list        # list records
omniscout memory show <id>   # show one record
omniscout memory note "idea: compare rerankers"   # standalone note
omniscout memory delete <id> # delete records
omniscout memory stats        # corpus statistics
omniscout memory clear        # wipe the entire corpus
```

`memory note`로 활성 페이지에 메모를 붙이거나 독립 메모를 작성하세요 — 메모도 인덱싱되어 결정과 맥락이 나중 검색에서 다시 떠오릅니다.

## 로컬 인덱스

관련 로컬 인덱스 명령어:

```bash
omniscout index ...          # manage the local search index (re-index, query cache)
omniscout crawl ...          # run and inspect local crawl jobs
omniscout extract-jobs ...   # inspect background extract jobs
```

Memory(`memory.sqlite`), 벡터 인덱스(`qdrant/`), 페이지 캐시(`cache/pages/`)는 모두 데이터 디렉터리에 있습니다 — [설정](/docs/cli/configuration)을 참고하세요. 기기를 절대 떠나지 않습니다. 외부로 나가는 트래픽은 실행한 검색과 가져온 URL뿐입니다.
