OmniScout is a self-contained, **terminal-native interface for the web**: a local browser brain for AI agents. It searches the web, extracts structured data, controls a real browser, automates desktop apps, and remembers everything — without leaving your laptop.

## How it fits together

- **CLI** — the `omniscout` command you (or your agent) type. Every command speaks JSON.
- **Daemon** — a long-lived background process at `127.0.0.1:7720` that keeps the browser warm, so actions are sub-second.
- **Backends** — Patchright (default, isolated Chromium) or an extension driving your existing browser with your real logins.

See [How it works](/docs/cli/architecture) for the full picture: `@eN` refs, sessions, profiles, action history, and the event stream.

## Install

```bash
pip install omniscout
omniscout install --skill
```

Full setup — browsers, daemon, models — is covered in [Installation](/docs/cli/installation). The 5-minute tour is [Quickstart](/docs/cli/quickstart).

## Design principles

- **Local-first** — no cloud account, API key, or hosted server. State, embeddings, and memory stay on your machine; the only outbound traffic is searches you run and URLs you fetch.
- **Agent-ready** — `--json` everywhere, stable `@eN` element refs, recorded action history with trace/replay, and skill files for Claude Code, Cursor, Codex, and Gemini CLI.
- **Real browser** — your Chromium, your cookies, your extensions. Log in once with a profile, reuse forever.

## Use

```bash
# Start the daemon (once)
omniscout daemon start

# Search the web
omniscout answer "what is the capital of france"

# Extract content from a URL
omniscout extract https://example.com

# Control a browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research a topic
omniscout research "AI agents in 2026"

# Build a knowledge graph
omniscout graph "Cursor"
```
