## Which command do I need?

| Command | Returns | Use when |
|---|---|---|
| `answer` | A synthesized answer with citations | You need a fact, not a link list (preferred) |
| `search` | Ranked URL hits | You need links to open, crawl, or cite yourself |
| `map` | Readable URLs on a site | You want to explore a whole domain |
| `warmup` | Nothing (preloads models) | Before a batch of calls, to cut first-call latency |

## answer — direct Q&A

```bash
omniscout answer "Who is the prime minister of India?"
omniscout answer "latest stable Rust version" --depth balanced
```

### Depth modes

`--depth` controls how much fetching happens behind the answer:

| Depth | What happens | Speed |
|---|---|---|
| `fast` | Answers from search snippets only | Fastest |
| `balanced` | Index + web fetch of top sources | Medium |
| `deep` | Crawls the top sources before answering | Slowest, most thorough |
| `auto` (default) | Picks based on the question | Varies |

### Answer engines

Two engines can synthesize the answer. The default comes from your settings (`omniscout settings engines`); override per call:

```bash
omniscout answer "..." --probe      # Probe Zero Mini (local LLM)
omniscout answer "..." --classic    # Classic extractive engine
omniscout answer "..." --probe-pro  # Probe Pro: structured-claim pipeline with crawl + verify
omniscout answer "..." --no-llm     # extractive fallback only, no LLM at all
```

Use `--limit/-n` to change how many search results are considered (default 10) and `--data` to include sources, timing, and retrieval diagnostics in the output.

## search — ranked web hits

```bash
omniscout search "vector database benchmarks 2026"
omniscout search "AI agents 2026" --limit 5
```

Results are fetched from the web and **reranked locally** with a sentence-transformers embedding model, so the top hits are semantically closest to your query — no LLM calls involved. Disable rerank per call with `--no-rerank`. `search` also has a bundled UI:

```bash
omniscout search ui   # open the local search UI (SearXNG at 127.0.0.1:8888)
```

### Search sources

Per call, pick a source with `--source` (`ddg | index | memory | hybrid`):

```bash
omniscout search "query" --source ddg
omniscout search "query" --source memory   # your remembered pages only
```

The default source lives in `config.toml` (`default_source`: `searxng | ddg | wikipedia | web`). Time- and region-hint the query with `--from/--to` (YYYY-MM-DD) and `--country`.

See [Configuration](/docs/cli/configuration) to change the default.

## map — crawl a site's URLs

```bash
omniscout map stripe.com
```

`map` produces a URL map of a domain — useful before a targeted `extract` or `research` run when you want to know what's on a site.

## warmup — preload models

```bash
omniscout warmup
```

Preloads the embedding and answer models into the daemon. Run once after install (or before a demo) so the first real call is fast instead of downloading and warming models on demand.

## Agent tips

- Prefer `answer` over `search` when you need a fact with citations.
- Pipe `--json` output through `jq` to pick fields: `omniscout search "topic" | jq '.hits[] | {title, url}'`.
- If results look off, try a more specific query or a different `--source` before assuming there's no information.
