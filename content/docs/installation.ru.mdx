## Требования

- **Python 3.11+** — проверьте командой `python --version`
- **Браузер на основе Chromium** — Chrome, Brave, Edge, Vivaldi, Opera, Arc или Chromium
- **macOS или Linux** — автоматизация рабочего стола (`computer`) пока поддерживается только на macOS

## Установка

```bash
pip install omniscout
```

Проверьте установку:

```bash
omniscout --version
omniscout --help
```

## Настройка браузера

OmniScout управляет настоящим браузером двумя способами:

| Бэкенд | Что это | Когда использовать |
|---|---|---|
| **Patchright** (по умолчанию) | OmniScout запускает собственный Chromium с постоянным профилем | Ноль настройки, изолированная автоматизация |
| **Extension** (опционально) | Управляет вашим существующим браузером с вашими реальными входами | Сайты, где вы уже вошли в аккаунт |

Проверьте, какие браузеры установлены, и доступность Chromium:

```bash
omniscout settings browsers
omniscout install
```

Чтобы управлять существующим браузером, укажите его OmniScout и загрузите расширение:

```bash
omniscout setup --browser dia
```

Это скачает расширение и откроет страницу расширений браузера. Выберите `Load unpacked`, укажите выведенную папку и убедитесь, что попап показывает `Daemon: connected`. См. [Как это работает](/docs/overview), чтобы понять различия бэкендов.

## Запуск daemon

Daemon — долгоживущий фоновый процесс, который держит браузер тёплым, чтобы каждое действие выполнялось за доли секунды:

```bash
omniscout daemon start
omniscout daemon status
```

Это нужно сделать только один раз — позже CLI сам запустит daemon при следующих командах. См. [Daemon и сессии](/docs/automation/sessions) про порты, логи и жизненный цикл.

## Прогрев моделей

Первый поиск или ответ скачивает локальную embedding-модель (далее она кэшируется). Предзагрузите её заранее, чтобы не ждать посреди задачи:

```bash
omniscout warmup
```

## Установка agent skills (опционально)

Если OmniScout будет управлять ИИ-агент, установите файлы skills, чтобы Claude Code, Cursor, Codex и Gemini CLI находили его автоматически:

```bash
omniscout install --skill
```

См. [Использование с ИИ-агентами](/docs/agents) для полной настройки агента.

## Обновление и удаление

```bash
pip install --upgrade omniscout   # update
pip uninstall omniscout           # remove the package
```

Чтобы стереть всё локальное состояние (профили, кэши, индексы, память):

```bash
rm -rf ~/Library/Application\ Support/omniscout/   # macOS
rm -rf ~/.local/share/omniscout/                   # Linux
```

Или переопределите путь через `OMNISCOUT_DATA_DIR`. См. [Конфигурация](/docs/configuration).
