## Какая команда мне нужна?

| Команда | Возвращает | Когда использовать |
|---|---|---|
| `answer` | Синтезированный ответ с цитатами | Нужен факт, а не список ссылок (предпочтительно) |
| `search` | Ранжированные попадания URL | Нужны ссылки, чтобы открыть, обойти или процитировать самому |
| `map` | Читаемые URL сайта | Хотите исследовать целый домен |
| `warmup` | Ничего (предзагружает модели) | Перед пачкой вызовов, чтобы снизить задержку первого вызова |

## answer — прямые вопросы-ответы

```bash
omniscout answer "Who is the prime minister of India?"
omniscout answer "latest stable Rust version" --depth balanced
```

### Режимы глубины

`--depth` управляет объёмом загрузки за ответом:

| Глубина | Что происходит | Скорость |
|---|---|---|
| `fast` | Ответ только по поисковым сниппетам | Самая быстрая |
| `balanced` | Индекс + веб-загрузка топ-источников | Средняя |
| `deep` | Обход топ-источников перед ответом | Самая медленная, самая тщательная |
| `auto` (по умолчанию) | Выбирается по вопросу | Разная |

### Движки ответов

Синтезировать ответ могут два движка. Движок по умолчанию берётся из настроек (`omniscout settings engines`); переопределите для одного вызова:

```bash
omniscout answer "..." --probe      # Probe Zero Mini (local LLM)
omniscout answer "..." --classic    # Classic extractive engine
omniscout answer "..." --probe-pro  # Probe Pro: structured-claim pipeline with crawl + verify
omniscout answer "..." --no-llm     # extractive fallback only, no LLM at all
```

Используйте `--limit/-n`, чтобы изменить число учитываемых результатов поиска (по умолчанию 10), и `--data`, чтобы включить в вывод источники, тайминги и диагностику retrieval.

## search — ранжированные веб-попадания

```bash
omniscout search "vector database benchmarks 2026"
omniscout search "AI agents 2026" --limit 5
```

Результаты загружаются из веба и **локально реранжируются** с помощью embedding-модели sentence-transformers, поэтому наверху оказываются семантически ближайшие к запросу попадания — без вызовов LLM. Отключите реранк для одного вызова флагом `--no-rerank`. У `search` есть и встроенный UI:

```bash
omniscout search ui   # open the local search UI (SearXNG at 127.0.0.1:8888)
```

### Источники поиска

Для одного вызова выберите источник флагом `--source` (`ddg | index | memory | hybrid`):

```bash
omniscout search "query" --source ddg
omniscout search "query" --source memory   # your remembered pages only
```

Источник по умолчанию хранится в `config.toml` (`default_source`: `searxng | ddg | wikipedia | web`). Подскажите запросу время и регион флагами `--from/--to` (YYYY-MM-DD) и `--country`.

См. [Конфигурация](/docs/cli/configuration), чтобы изменить значение по умолчанию.

## map — обход URL сайта

```bash
omniscout map stripe.com
```

`map` строит карту URL домена — полезно перед точечным запуском `extract` или `research`, когда нужно понять, что есть на сайте.

## warmup — предзагрузка моделей

```bash
omniscout warmup
```

Предзагружает embedding-модель и модели ответов в daemon. Запустите один раз после установки (или перед демо), чтобы первый реальный вызов был быстрым, а не скачивал и прогревал модели по требованию.

## Советы для агентов

- Предпочитайте `answer` вместо `search`, когда нужен факт с цитатами.
- Пропускайте вывод `--json` через `jq`, чтобы выбрать поля: `omniscout search "topic" | jq '.hits[] | {title, url}'`.
- Если результаты выглядят странно, попробуйте более конкретный запрос или другой `--source`, прежде чем считать, что информации нет.
