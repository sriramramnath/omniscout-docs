## 전역 옵션

모든 명령어가 지원합니다:

- `--json` — stdout에 기계가 읽을 수 있는 JSON 출력
- `--verbose`, `-v` — 자세한 stderr 로깅
- `--version` — 버전 출력 후 종료

JSON 출력을 기본값으로 만들려면 환경에 `OMNISCOUT_JSON=1`을 설정하세요. 전체 JSON 규약과 모든 환경 변수는 [설정](/docs/cli/configuration)을 참고하세요.

## 브라우저 명령어

전체 가이드: [브라우저 자동화](/docs/cli/browser).

| 명령어 | 설명 |
|---------|--------------|
| `browser navigate <url>` / `open` | URL 열기 (`--profile`, `--session`, `--new-tab`, `--headful`, `--wait-until`, `--auto-captcha`) |
| `browser back/forward/reload` | 히스토리 내비게이션 |
| `browser snapshot [--refs-only]` | `@eN` ref가 있는 상호작용 요소 (`--overlay`로 시각화) |
| `browser observe "<hint>"` | 자연어 지시에 대한 후보 ref 찾기 |
| `browser act "<instruction>"` | 페이지 동작 해석 + 수행 (`--value`, `--dry-run`) |
| `browser click <ref>` | 클릭 (`--button`, `--clicks`, `--mod`, `--coord`) |
| `browser fill <ref> <value>` | 필드 내용 교체 |
| `browser type <ref> <text>` | 텍스트 이어 쓰기 (`--delay-ms`) |
| `browser paste <ref> <text>` | 커서에 삽입 |
| `browser select <ref> <option>` | 네이티브 `<select>` |
| `browser scroll [up\|down]` | 페이지/요소 스크롤 (`--amount`, `--ref`) |
| `browser key <combo>` | 키보드 단축키 (`Enter`, `cmd+s`, …) |
| `browser hover <ref>` | 요소/좌표에 마우스 올리기 |
| `browser upload <ref> <files>` | `<input type=file>`에 파일 첨부 |
| `browser is <ref> <state>` | visible/hidden/enabled/disabled/checked/editable |
| `browser get title/url/text/html` | 페이지 속성 읽기 |
| `browser eval <js>` | JavaScript 실행 후 값 반환 |
| `browser extract-visible` | 보이는 텍스트, 선택적으로 `--schema` 가공 |
| `browser find-image` | 뷰포트에서 이미지 템플릿 찾기 |
| `browser screenshot [-o PATH]` | PNG/JPEG (`--full-page`, `--ref`, `--delay`, `--format`) |
| `browser pdf [-o PATH]` | PDF로 렌더링 (`--paper`, `--landscape`, `--scale`) |
| `browser wait …` | `text`, `selector`, `networkidle`, `url` (+ `--ms`, `--timeout-ms`) |
| `browser mouse scroll/move` | 좌표에 raw 마우스 입력 |
| `browser tab list/close/switch` | 세션 내 탭 관리 |
| `browser network start/stop/list/tail/detail` | 요청/응답 캡처 |
| `browser console start/stop/list/tail` | 콘솔 + JS 오류 캡처 |
| `browser login <url>` | headful 로그인, 블로킹 (`--profile`, `--done`, `--success-pattern`) |
| `browser captcha` | 감지/해결 (`none\|2captcha\|capsolver\|manual`, `--detect-only`) |
| `browser close [--all]` | 하나의 세션 또는 전체 닫기 |

## 환경 변수

| 변수 | 용도 |
|---|---|
| `OMNISCOUT_JSON=1` | 모든 명령어에 JSON 출력 강제 |
| `OMNISCOUT_DAEMON_AUTO_START=0` | daemon 자동 시작 안 함 |
| `OMNISCOUT_DAEMON_PORT` | daemon 포트 재정의 (기본값 7720) |
| `OMNISCOUT_DATA_DIR` | 데이터 디렉터리 재정의 |
| `OMNISCOUT_BROWSER` | 브라우저 id (설정 재정의) |
| `OMNISCOUT_EMBED_LOCAL_ONLY=0` | 런타임 Hugging Face 가져오기 허용 |
| `TWOCAPTCHA_API_KEY` / `CAPTCHA_API_KEY` | CAPTCHA 솔버 키 |

설정 키와 데이터 구조 전체 목록: [설정](/docs/cli/configuration).
