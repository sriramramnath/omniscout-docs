## Daemon lifecycle

The daemon (`127.0.0.1:7720` by default) holds the browser open so actions stay sub-second:

```bash
omniscout daemon start     # idempotent — returns status if already up
omniscout daemon status    # health, version, active sessions
omniscout daemon restart
omniscout daemon stop      # SIGTERM, then SIGKILL after 5s
omniscout daemon logs      # tail the daemon log (add --follow)
```

Most commands auto-start the daemon if it's down. Override the port with `OMNISCOUT_DAEMON_PORT` (and `omniscout daemon start --port 7721`); disable auto-start with `OMNISCOUT_DAEMON_AUTO_START=0`.

## Debugging: trace, replay, watch

Every daemon action is recorded to a JSONL history (last 10k commands):

```bash
omniscout daemon trace     # inspect the action history
omniscout daemon replay    # re-run recorded actions
omniscout daemon watch     # subscribe to the live event stream (SSE)
```

These are the fastest way to see what an agent actually did — `trace` for forensics, `watch` for live monitoring.

## Sessions vs profiles

| | Session (`--session`) | Profile (`--profile`) |
|---|---|---|
| What | A named tab group in the live daemon | A persistent browser user-data-dir on disk |
| Survives daemon restart? | No | Yes |
| Keeps cookies/logins? | While alive | Across runs |
| Manage with | `omniscout session …` | `omniscout profile …` |

Use **sessions** to isolate parallel workflows sharing one daemon; use **profiles** to separate identities (work vs personal) or keep logins across restarts.

### Sessions

```bash
omniscout session start          # start a session, prints id + WS endpoint
omniscout session list           # active sessions
omniscout session attach <id>    # connection info (CDP WS endpoint)
omniscout session kill <id>      # kill one (or all) sessions
```

Pass `--session <name>` on any `browser`/`computer` command to run inside that session. Top-level shortcuts `open`, `snapshot`, `context`, and `reset` operate on the default session's workflow state.

### Profiles

```bash
omniscout profile create work
omniscout profile list
omniscout profile delete old
```

Then attach a profile to any browser run:

```bash
omniscout browser navigate https://github.com/notifications --profile work
omniscout browser login https://github.com/login --profile work  # log in once, reuse
```

Profiles live under `profiles/` in the data dir. Keep them outside the repository — they contain cookies.

## Settings

```bash
omniscout settings show        # current settings + resolved browser target
omniscout settings browsers    # supported browsers, and which are installed
omniscout settings engines     # supported answer engines
omniscout settings set browser brave
```

Settings persist to `config.toml` — see [Configuration](/docs/cli/configuration) for every key and environment override.
