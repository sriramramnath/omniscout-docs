## Установка

```bash
pip install omniscout
omniscout install --skill
```

## Использование

```bash
omniscout daemon start

# Поиск
omniscout answer "what is the capital of france"

# Извлечение
omniscout extract https://example.com

# Браузер
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Исследование
omniscout research "AI agents in 2026"

# Граф знаний
omniscout graph "Cursor"
```

## Что внутри

| Команда | Что делает |
|---|---|
| `omniscout answer` | Прямые вопросы-ответы с цитатами |
| `omniscout search` | Веб-поиск с реранжированием |
| `omniscout extract` | Загрузка URL с возвратом чистого содержимого |
| `omniscout research` | Многошаговый исследовательский пайплайн |
| `omniscout graph` | Построение графа знаний |
| `omniscout browser` | Управление браузером |
| `omniscout computer` | Автоматизация рабочего стола (macOS) |
| `omniscout remember` | Сохранение URL в памяти |
| `omniscout daemon` | Управление фоновым сервисом |

## Вывод JSON

```bash
export OMNISCOUT_JSON=1  # структурированный вывод для агентов
```

## Локальность

Облачный аккаунт, API-ключ или внешний сервер не требуются. Единственный исходящий трафик — это поиски DuckDuckGo и URL, которые вы явно запрашиваете.
