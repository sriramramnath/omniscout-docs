すべてのコマンドは`omniscout --help`で、オプションは`omniscout <command> --help`で確認できます。

## トップレベルコマンド

| コマンド | 内容 | 使用場面 |
|---------|--------------|-------------|
| `search` | セマンティックリランク付きWeb検索（オプション） | URLや事実のクイック検索 |
| `answer` | Web結果を取得してLLMで統合 | 引用付きの直接Q&A。`search`より推奨 |
| `map` | サイトをクロールしてURLマップを作成 | ドメイン全体の探索 |
| `warmup` | デーモン内の埋め込み・回答モデルを事前読み込み | 初回呼び出しの遅延を削減 |
| `remember` | URLにアクセスしてコンテンツを抽出・ブラウザメモリに保存 | 情報を保存して後で呼び出し |
| `extract` | URLやクエリを取得して読みやすい・構造化データを返す | ページから生テキストやJSONを取得 |
| `open` | 管理ブラウザでURLまたは最新の検索結果インデックスを開く | 管理Chromiumでページを実行 |
| `snapshot` | `@e`参照付きアクセシビリティスナップショットを取得 | 後のUI操作のためページ構造を確認 |
| `context` | 現在のワークフロー継続状態を表示 | マルチステップフローのデバッグ・再開 |
| `reset` | 継続状態をリセット | 新しいセッションを開始 |
| `auto` | 入力を最適なコマンドに自動振り分け | シンプルなワンライナー利用 |
| `research` | マルチステップ：検索 → クロール → 抽出 → リランク → 要約 | 本格的なリサーチパイプライン |
| `graph` | エンティティの構造化ナレッジグラフを構築 | 事実をノード・edgeに整理 |
| `install` | 自動化用Chromiumブラウザを確認（またはダウンロード） | 初回セットアップ |
| `settings` | ユーザー設定の表示・変更 | 設定の微調整 |
| `browser` | Playwrightベースの直接Chromium自動化 | 複雑なWeb UIワークフロー |
| `computer` | ネイティブデスクトップ自動化（macOS） | OSアプリ・ファイル・クリップボード等の操作 |
| `daemon` | 常駐ブラウザ制御デーモンを管理 | バックグラウンドサービスの開始・停止 |
| `index` | ローカル検索インデックスを管理 | ローカルキャッシュの再インデックス・検索 |
| `crawl` | ローカルのクロールジョブを実行・確認 | 一括サイトクロール |
| `record` | デーモン操作を名前付きマクロに記録 | 再利用可能なスクリプトを作成 |
| `macro` | 保存済みマクロの一覧・実行 | 記録済み操作を再生 |
| `replay` | 記録済みブラウザ操作を再生 | フローのデバッグ・繰り返し |
| `workflow` | 継続ワークフローをエクスポート・表示 | プロセスの保存・共有 |
| `monitor` | URLの変更を継続監視 | コンテンツ更新時に通知 |
| `profile` | 永続ブラウザプロファイルを管理 | コンテキストの分離（仕事用・個人用） |
| `session` | 常駐ブラウザセッションを管理 | Cookie・ログインを維持 |
| `memory` | ブラウザメモリ — 記憶済み訪問・メモ | 保存済みスニペットを取得 |

## グローバルオプション

すべてのコマンドが対応：

- `--json` — 機械可読JSONをstdoutに出力
- `--verbose`、`-v` — 詳細なstderrログ
- `--version` — バージョンを表示して終了

環境変数`OMNISCOUT_JSON=1`を設定するとJSON出力がデフォルトになります。

## ブラウザコマンド

| コマンド | 内容 |
|---------|--------------|
| `browser navigate <url>` | アクティブタブでURLを開く |
| `browser snapshot --refs-only` | `@eN`参照付きの操作可能要素を取得 |
| `browser click <ref>` | `@eN`参照で要素をクリック |
| `browser fill <ref> <value>` | フォームフィールドに入力 |
| `browser type <ref> <text>` | フィールドにテキストを入力 |
| `browser scroll [up\|down]` | ページをスクロール |
| `browser key <combo>` | キーボードショートカットを押す |
| `browser screenshot [-o PATH]` | スクリーンショットを撮る |
| `browser pdf [-o PATH]` | PDFを生成 |
| `browser wait text <substring>` | テキストの出現を待つ |
| `browser login <url>` | ヘッドフルログインウィンドウを開く |
| `browser captcha` | CAPTCHAを検出・解決 |
| `browser close --all` | すべてのセッションを閉じる |

## コンピューターコマンド（macOS）

| コマンド | 内容 |
|---------|--------------|
| `computer navigate <target>` | アプリ・ファイル・URLを開く |
| `computer type <text>` | フォーカス中のウィンドウに入力 |
| `computer key <combo>` | キーボードショートカットを送信 |
| `computer screenshot` | 画面をキャプチャ |
| `computer clipboard get` | クリップボードを読み取る |
| `computer clipboard set <text>` | クリップボードに書き込む |
| `computer window list` | 開いているウィンドウを一覧表示 |
| `computer window activate <title>` | ウィンドウを前面に表示 |
| `computer ui snapshot` | UI要素の参照を取得 |
| `computer ui click <ref>` | UI要素をクリック |

## 環境変数

| 変数 | 用途 |
|---|---|
| `OMNISCOUT_JSON=1` | すべてのコマンドでJSON出力を強制 |
| `OMNISCOUT_DAEMON_AUTO_START=0` | デーモンを自動起動しない |
| `OMNISCOUT_DAEMON_PORT` | デーモンポートを上書き（デフォルト7720） |
| `OMNISCOUT_DATA_DIR` | データディレクトリを上書き |
