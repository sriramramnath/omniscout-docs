OmniScoutは3つの要素で構成されます：

1. **CLI** — 入力する`omniscout`コマンド
2. **Daemon** — ブラウザを開いたまま保持する常駐バックグラウンドプロセス
3. **Backends** — Playwright（デフォルト）またはChrome拡張機能

```mermaid
flowchart LR
  CLI["CLI — omniscout command"] -->|"HTTP POST"| Daemon["Daemon — background process"]
  Daemon --> Playwright["Playwright (default)"]
  Daemon --> Extension["Chrome extension (opt-in)"]
  Playwright --> Browser["Browser"]
  Extension --> Browser
```

## 主要概念

### `@eN`参照

`snaphot`を実行すると、OmniScoutは安定した要素参照（`@e1`、`@e2`、…）付きでページのアクセシビリティツリーを返します。これらを使ってクリック・入力・操作します — CSSの変更に影響されません。

### デーモン

デーモンはPlaywrightをウォーム状態に保つため、すべての操作が1秒未満で実行されます。`omniscout daemon start`で一度起動します。

### バックエンド

- **Playwright**（デフォルト）：OmniScoutが永続プロファイル付きの独自Chromeを起動
- **Chrome拡張機能**（オプトイン）：実際のログイン情報を持つ実際のChromeを操作

### プロファイル

永続ブラウザプロファイルはCookieとログイン状態を保存します。`omniscout profile create work`で作成し、各コマンドで`--profile work`を使います。

## データの保存場所

| プラットフォーム | パス |
|---|---|
| macOS | `~/Library/Application Support/omniscout/` |
| Linux | `~/.local/share/omniscout/` |

`OMNISCOUT_DATA_DIR`で上書きできます。
