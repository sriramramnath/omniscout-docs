OmniScout даёт ИИ-агентам возможность искать в интернете, извлекать контент, управлять браузерами и автоматизировать задачи рабочего стола — всё локально, без облака.

## Установка

```bash
pip install omniscout
omniscout install --skill
```

## Использование

```bash
# Запуск демона (один раз)
omniscout daemon start

# Поиск в интернете
omniscout answer "what is the capital of france"

# Извлечение контента из URL
omniscout extract https://example.com

# Управление браузером
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Исследование темы
omniscout research "AI agents in 2026"

# Построение графа знаний
omniscout graph "Cursor"
```

## Что вы можете делать

| Команда | Что делает |
|---------|--------------|
| `search` | Веб-поиск с опциональным семантическим реранжированием |
| `answer` | Прямые вопросы-ответы с цитатами (предпочтительнее, чем `search`) |
| `extract` | Загрузка URL с возвратом чистого Markdown |
| `research` | Многошаговый процесс: search → crawl → extract → summarize |
| `graph` | Построение структурированного графа знаний |
| `browser` | Управление браузером (navigate, click, fill, screenshot) |
| `computer` | Автоматизация рабочего стола (macOS) |
| `remember` | Сохранение URL в памяти браузера для последующего использования |
| `install` | Первоначальная настройка |
| `daemon` | Управление фоновым сервисом |
