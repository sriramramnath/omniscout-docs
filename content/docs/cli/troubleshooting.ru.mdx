Исправления упорядочены по месту возникновения: взаимодействие с браузером, вход/CAPTCHA, установка/рантайм, поиск/извлечение, daemon и данные. Если ничего не помогло, запускайте команды с `-v` и прикладывайте вывод `omniscout daemon trace` к вашему [GitHub issue](https://github.com/sriramramnath/omniscout/issues).

## Взаимодействие с браузером

### `@eN` ref не найден

Страница изменилась с момента последнего `snapshot`. Сделайте снимок заново и используйте новый ref:

```bash
omniscout browser snapshot --refs-only
omniscout browser click '@e7'
```

Никогда не переиспользуйте refs между `navigate`, `reload` или отправками форм.

### Snapshot не показывает полезных refs

Страница может ещё грузиться. Дождитесь контента перед snapshot:

```bash
omniscout browser wait networkidle
omniscout browser wait text "expected heading"
omniscout browser snapshot --refs-only
```

Для canvas/WebGL-страниц без accessibility-дерева откатитесь на `screenshot` + клики `--coord` или `observe`/`act`.

### Клик ничего не сделал

Сначала проверьте, что элемент actionable, затем попробуйте клавиатурные альтернативы:

```bash
omniscout browser is '@e3' visible
omniscout browser is '@e3' enabled
omniscout browser hover '@e3'
omniscout browser key Enter
```

### Скриншот пустой

```bash
# Wait for loading
omniscout browser screenshot https://example.com --delay 3 --out /tmp/page.png

# Full page
omniscout browser screenshot https://example.com --full-page --out /tmp/full.png
```

Пусто + `wait networkidle` всё ещё пусто обычно означает, что daemon потерял вкладку — `browser close --all` и navigate заново.

## Вход и CAPTCHA

### Вход никогда не завершается

Используйте сигнал `--done` из другого шелла:

```bash
# Terminal A:
omniscout browser login https://app.example.com --profile work

# Terminal B (after you log in):
omniscout browser login --done
```

Если сайт странно редиректит, передайте `--success-pattern "dashboard|/app"`, чтобы вход завершался по совпадению URL вместо ожидания полных 5 минут `--timeout-ms`.

### CAPTCHA блокирует навсегда

Решите её в видимом окне или используйте сторонний решатель:

```bash
export TWOCAPTCHA_API_KEY=...
omniscout browser captcha --solver 2captcha
```

Начните с `omniscout browser captcha --detect-only`, чтобы убедиться, что это действительно CAPTCHA, а не bot-wall. `navigate --auto-captcha` решает проверки сразу после загрузки.

### Расширение сообщает `backend_unavailable`

1. Откройте `chrome://extensions` — убедитесь, что расширение загружено
2. Нажмите на значок расширения — переподключитесь, если отключено
3. Или уберите `--backend extension`, чтобы использовать Patchright

## Установка и рантайм

### Ошибка версии Python

```bash
python --version  # needs 3.11+
pip install omniscout
```

### Chrome не найден

```bash
omniscout settings browsers          # see what's installed
omniscout settings set browser edge  # or brave, vivaldi, etc.
```

Для своего пути: `browser = "custom"` плюс `browser_executable` в `config.toml` (см. [Конфигурация](/docs/cli/configuration)).

### Первый поиск медленный

Это одноразовая загрузка embedding-модели. Предзагрузите её: `omniscout warmup`. Далее офлайн, если не `OMNISCOUT_EMBED_LOCAL_ONLY=0`.

## Поиск и извлечение

### Поиск не возвращает результатов

```bash
omniscout search "more specific query"
omniscout search "query" --source ddg
omniscout search "query" --no-rerank   # check if the reranker is hiding hits
```

### Извлечение возвращает мусор

- Попробуйте `--format text` (отбрасывает битую разметку) или `--no-cache` (протухший кэш).
- Для JS-тяжёлых страниц используйте браузер: `navigate` → `extract-visible` вместо `extract`.
- Для pulls целого сайта используйте режим экспорта сайта с фильтрами `--include/--exclude` (см. [Извлечение](/docs/cli/extraction)).

## Daemon, профили, сессии

### Daemon не запускается

```bash
omniscout daemon stop
omniscout daemon start
lsof -i :7720                       # check if port is in use
omniscout daemon start --port 7721   # use different port
```

Если порт 7720 занят другим инструментом, экспортируйте `OMNISCOUT_DAEMON_PORT=7721`, чтобы каждая команда использовала новый порт.

### Копятся протухшие вкладки

```bash
omniscout session list
omniscout session kill <id>
omniscout browser close --all
```

### Потеря входов после рестарта

Сессии не переживают рестарты daemon — профили переживают. Входите с `--profile <name>` и передавайте тот же профиль в later runs (см. [Daemon и сессии](/docs/cli/sessions)).

## JSON и агенты

- Пустой вывод `--json` с ошибками на экране: ошибки идут в `stderr` по дизайну — проверяйте код выхода и `stderr`, а не `stdout`.
- Добавьте `-v` для подробного логирования daemon/HTTP, когда команда висит.

## Радикальные меры

```bash
pip install --upgrade omniscout
omniscout daemon restart
rm -rf ~/Library/Application\ Support/omniscout/   # macOS — wipes profiles, cache, memory
rm -rf ~/.local/share/omniscout/                   # Linux
```

## FAQ

**Мои данные отправляются в облако?**
Нет. Единственный исходящий трафик — поиски DuckDuckGo и URL, которые вы явно загружаете. Одноразовая загрузка модели кэшируется локально.

**Могу ли я использовать OmniScout без Chrome?**
Нужен браузер семейства Chromium. Установите Chrome/Chromium или настройте свой путь через `omniscout install --browser custom --browser-executable <path>`.

**Как обновиться?**
```bash
pip install --upgrade omniscout
```

**Как стереть все данные?**
```bash
rm -rf ~/Library/Application\ Support/omniscout/   # macOS
rm -rf ~/.local/share/omniscout/                   # Linux
```
