OmniScout Cloud는 **사용량 기반 요금제만** 사용합니다. 구독 티어, 월간 포함 시간, 플랜 기반 API 제한이 없습니다.

## 요금 공식

```
customer_charge = actual_infrastructure_cost × 1.30
```

이는 **기본 비용에 30% 할증** (원가 + 30%)이며, 30% 총마진이 아닙니다.

## 과금 리소스

| 리소스 | 측정 | Stripe 미터 이벤트 |
|---|---|---|
| 컴퓨터 런타임 | 세션 준비 → 삭제까지 초 단위 | `computer_runtime_seconds` |
| 브라우저 런타임 | 세션 준비 → 삭제까지 초 단위 | `browser_runtime_seconds` |
| 검색 | `POST /v0/search` 요청당 | `search_requests` |
| 답변 | `POST /v0/answer` 요청당 | `answer_requests` |

`GET /v0/sessions/{id}` 및 `POST /v0/sessions/{id}/actions` 같은 API 호출은 API 사용량으로 **측정되지 않습니다**. 악용 방지, 동시성 상한, 세션 TTL, 지출 한도의 적용을 받으며 무제한입니다.

## 2계층 결제

| 계층 | 역할 |
|---|---|
| **Convex 사용량 원장** | 감사 추적, 실시간 비용 추정, 지출 한도 적용 |
| **Stripe Billing** | 결제 수단, 미터링 사용량, 인보이스, 고객 포털 |

## GET /v0/usage

현재 기간 사용량, 예상 요금, 활성 세션, 지출 한도, 청구 상태를 반환합니다.

```json
{
  "period": "2026-09",
  "usage": {
    "computer_runtime_seconds": 3600,
    "browser_runtime_seconds": 1200,
    "search_count": 42,
    "answer_count": 8
  },
  "costs": {
    "underlying_cost_usd": 12.5,
    "markup_multiplier": 1.3,
    "estimated_charge_usd": 16.25
  },
  "spending_limit_usd": 100,
  "spending_limit_remaining_usd": 83.75,
  "billing_status": "active"
}
```

## 지출 보호

월간 지출 한도를 초과하면 과금 작업은 `spending_limit_exceeded`와 함께 `402`를 반환합니다. `past_due` 청구 상태인 계정은 결제가 해결될 때까지 차단될 수 있습니다.

## 대시보드

[대시보드 결제](https://api.omniscout.xyz/dashboard/billing)에서 사용량과 예상 요금을 확인하세요. 해당 페이지에서 Stripe 고객 포털을 열어 결제 수단과 인보이스를 관리하세요.
