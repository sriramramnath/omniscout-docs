## config.toml

Create `config.toml` in your platform's config directory:

| Platform | Path |
|---|---|
| macOS | `~/Library/Application Support/omniscout/config.toml` |
| Linux | `~/.config/omniscout/config.toml` |

```toml
default_source = "searxng"   # searxng | ddg | wikipedia | web
search_limit = 10
research_results = 8
request_throttle_seconds = 1.0
embedding_model = "sentence-transformers/all-MiniLM-L6-v2"
browser = "chrome"                    # chrome | edge | brave | vivaldi | opera | arc | chromium | custom
# browser_executable = "/path/to/browser"  # only needed for 'custom'
```

Prefer the CLI over hand-editing — `omniscout settings set` writes the same file:

```bash
omniscout settings set browser brave
omniscout settings show
```

Check install state and engines with `omniscout install`, `omniscout settings browsers`, and `omniscout settings engines`.

## Environment variables

| Variable | Purpose |
|---|---|
| `OMNISCOUT_JSON=1` | Force JSON output on every command |
| `OMNISCOUT_DAEMON_AUTO_START=0` | Don't auto-start the daemon |
| `OMNISCOUT_DAEMON_PORT` | Daemon port (default 7720) |
| `OMNISCOUT_DATA_DIR` | Override the data directory |
| `OMNISCOUT_BROWSER` | Browser id (overrides config) |
| `OMNISCOUT_EMBED_LOCAL_ONLY=0` | Allow runtime Hugging Face fetches |
| `TWOCAPTCHA_API_KEY` / `CAPTCHA_API_KEY` | CAPTCHA solver key |
| `OMNISCOUT_API_KEY` | Cloud API key (Cloud SDK/CLI use) |
| `OMNISCOUT_BASE_URL` | Cloud base URL (default production) |

Legacy `HARNESS_*` equivalents are still accepted.

## JSON output contract

Every command speaks JSON — the agent integration surface:

```bash
omniscout --json answer "What is local-first software?"
export OMNISCOUT_JSON=1   # same for all commands in this shell
```

With JSON on, `stdout` is a structured payload and logs go to `stderr` (add `-v/--verbose` for more). Pipe through `jq`:

```bash
omniscout search "topic" | jq '.hits[] | {title, url}'
```

Or skip the CLI and talk to the daemon directly:

```bash
curl -X POST http://127.0.0.1:7720/command \
  -H 'Content-Type: application/json' \
  -d '{"action":"navigate","args":{"url":"https://example.com"},"session":"demo"}'
```

See [Using with AI agents](/docs/cli/agents) for the full agent loop (JSON, trace/replay/watch, error kinds).

## On-disk state

| Path (under data dir) | Purpose |
|---|---|
| `profiles/` | Persistent browser user-data-dirs |
| `qdrant/` | Embedded vector index |
| `models/sentence-transformers/` | Prefetched embedding model |
| `memory.sqlite` | Browser memory (visits + notes) |
| `sessions.sqlite` | Long-lived session registry |
| `cache/pages/` | Content-hashed HTML cache |
| `daemon/` | PID, port, logs, action history, session restore |

Keep profiles and model/cache data outside version control.
