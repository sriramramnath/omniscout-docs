ブラウザメモリは訪問済みページと書き留めたメモに対するローカルベクトルインデックスです。今保存して、あとで意味的に思い出します — LLM呼び出しは不要です。

## ページを記憶します

```bash
omniscout remember https://example.com/blog/post
```

`remember`はURLにアクセスしてコンテンツを抽出し、`memory.sqlite`に保存します。あとで`memory`で検索します：

```bash
omniscout memory "neural networks in production"
```

`memory`は保存済みページをクエリとの意味的類似度でランク付けするため、言い換えでも一致します — 正確なタイトルやURLは不要です。

## 自分のメモリを先に検索します

`search`コマンドはWebの代わりにメモリを対象にできます：

```bash
omniscout search "query" --source memory
```

エージェントでは便利です：新しいWeb検索に時間をかける前に、すでに見た内容（`--source memory`）を確認します。

## コーパスを管理します

`memory`はクエリだけでなくコマンドグループです：

```bash
omniscout memory "query"     # semantic search over remembered pages
omniscout memory list        # list records
omniscout memory show <id>   # show one record
omniscout memory note "idea: compare rerankers"   # standalone note
omniscout memory delete <id> # delete records
omniscout memory stats        # corpus statistics
omniscout memory clear        # wipe the entire corpus
```

`memory note`でアクティブページへのメモを付与（または単独メモを作成）します — メモもインデックス化されるため、判断や文脈があとの検索で再浮上します。

## ローカルインデックス

関連するローカルインデックスコマンド：

```bash
omniscout index ...          # manage the local search index (re-index, query cache)
omniscout crawl ...          # run and inspect local crawl jobs
omniscout extract-jobs ...   # inspect background extract jobs
```

メモリ（`memory.sqlite`）、ベクトルインデックス（`qdrant/`）、ページキャッシュ（`cache/pages/`）はすべてデータディレクトリにあります — [設定](/docs/cli/configuration)をご覧ください。お使いのマシンの外に出ることはありません。外部送信は実行した検索と取得したURLのみです。
