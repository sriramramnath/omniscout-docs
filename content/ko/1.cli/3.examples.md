자주 쓰는 작업용 복사-붙여넣기 레시피.

## 빠른 참조

```bash
omniscout daemon start                              # 1. 데몬 시작
omniscout browser navigate https://example.com      # 2. 브라우저 구동
omniscout browser snapshot --refs-only              # 3. @eN 참조 찾기
omniscout browser click '@e3'                       # 4. 참조에 동작 수행
omniscout browser screenshot --out /tmp/out.png     # 5. 상태 캡처
omniscout browser close --all                       # 6. 정리
```

## 검색 및 답변

```bash
# 한 줄 사실 답변
omniscout answer "who is the prime minister of india"
omniscout answer "what is the capital of france"

# 순위 매겨진 결과를 보여주는 웹 검색
omniscout search "AI agents 2026" --limit 5
```

## 페이지에서 콘텐츠 추출

```bash
omniscout extract https://example.com > /tmp/page.md
```

## 주제 리서치

```bash
omniscout research "vector database benchmarks 2026" --results 10
```

## 지식 그래프 구축

```bash
omniscout graph "Cursor"
omniscout graph "cursor.com"          # 사이트 전용 모드
```

## 이동 및 상호작용

```bash
omniscout browser navigate https://news.ycombinator.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/hn.png
omniscout browser close --all
```

## 양식 작성

```bash
omniscout browser navigate https://duckduckgo.com
omniscout browser snapshot --refs-only
SEARCH_REF=$(jq -r '.refs[] | select(.role == "searchbox") | .ref' | head -1)
omniscout browser fill "$SEARCH_REF" "local-first AI agents"
omniscout browser key Enter
```

## 로그인하고 프로필 재사용

```bash
# 터미널 A: 브라우저를 열고 대기
omniscout browser login https://github.com/login --profile work

# 터미널 B (로그인 후):
omniscout browser login --done

# 이제 프로필 재사용
omniscout browser navigate https://github.com/notifications --profile work
omniscout browser screenshot --out /tmp/notifs.png
```

## 네트워크 요청 캡처

```bash
omniscout browser network start
omniscout browser navigate https://vercel.com/pricing
omniscout browser scroll down --amount 10
omniscout browser network stop
omniscout browser network list --filter "stripe|payment"
```

## 전체 페이지 스크린샷 촬영

```bash
omniscout browser screenshot https://example.com --full-length --out /tmp/full.png
```

## 여러 탭

```bash
omniscout browser navigate https://example.com --session multi
omniscout browser navigate https://news.ycombinator.com --new-tab --session multi
omniscout browser tab list --session multi
omniscout browser tab switch 0 --session multi
```

## 에이전트용 JSON

```bash
export OMNISCOUT_JSON=1

omniscout search "topic"          | jq '.hits[] | {title, url}'
omniscout browser snapshot        | jq '.refs[] | select(.role == "button")'
omniscout extract https://...     | jq '{title, word_count}'
omniscout research "topic"        | jq '.passages[0:3]'
```
