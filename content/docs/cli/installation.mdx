## Requirements

- **Python 3.11+** — check with `python --version`
- **A Chromium-based browser** — Chrome, Brave, Edge, Vivaldi, Opera, Arc, or Chromium
- **macOS or Linux** — desktop automation (`computer`) currently supports macOS only

## Install

```bash
pip install omniscout
```

Verify the install:

```bash
omniscout --version
omniscout --help
```

## Set up a browser

OmniScout drives a real browser two ways:

| Backend | What it is | When to use it |
|---|---|---|
| **Patchright** (default) | OmniScout launches its own Chromium with a persistent profile | Zero setup, isolated automation |
| **Extension** (opt-in) | Drives your existing browser with your real logins | Sites where you're already logged in |

Check which browsers are installed and verify Chromium availability:

```bash
omniscout settings browsers
omniscout install
```

To drive your existing browser instead, point OmniScout at it and load the extension:

```bash
omniscout setup --browser dia
```

This downloads the extension and opens the browser's extensions page. Choose `Load unpacked`, select the printed folder, and confirm the popup says `Daemon: connected`. See [How it works](/docs/cli/architecture) for how backends differ.

## Start the daemon

The daemon is a long-lived background process that keeps the browser warm so every action is sub-second:

```bash
omniscout daemon start
omniscout daemon status
```

You only need to do this once — the CLI auto-starts the daemon on later commands. See [Daemon & sessions](/docs/cli/sessions) for ports, logs, and lifecycle.

## Warm the models

The first search or answer downloads a local embedding model (cached afterwards). Preload it up front to avoid waiting mid-task:

```bash
omniscout warmup
```

## Install agent skills (optional)

If an AI agent will drive OmniScout, install the skill files so Claude Code, Cursor, Codex, and Gemini CLI auto-discover it:

```bash
omniscout install --skill
```

See [Using with AI agents](/docs/cli/agents) for the full agent setup.

## Update and uninstall

```bash
pip install --upgrade omniscout   # update
pip uninstall omniscout           # remove the package
```

To wipe all local state (profiles, caches, indexes, memory):

```bash
rm -rf ~/Library/Application\ Support/omniscout/   # macOS
rm -rf ~/.local/share/omniscout/                   # Linux
```

Or override the location with `OMNISCOUT_DATA_DIR`. See [Configuration](/docs/cli/configuration).
