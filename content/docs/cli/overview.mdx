OmniScout gives AI agents the ability to search the web, extract content, control browsers, and automate desktop tasks — all locally, no cloud required.

## Install

```bash
pip install omniscout
omniscout install --skill
```

## Use

```bash
# Start the daemon (once)
omniscout daemon start

# Search the web
omniscout answer "what is the capital of france"

# Extract content from a URL
omniscout extract https://example.com

# Control a browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research a topic
omniscout research "AI agents in 2026"

# Build a knowledge graph
omniscout graph "Cursor"
```

## What you can do

| Command | What it does |
|---------|--------------|
| `search` | Web search with optional semantic rerank |
| `answer` | Direct Q&A with citations (preferred over `search`) |
| `extract` | Fetch a URL and return clean Markdown |
| `research` | Multi-step: search → crawl → extract → summarize |
| `graph` | Build a structured knowledge graph |
| `browser` | Control a browser (navigate, click, fill, screenshot) |
| `computer` | Desktop automation (macOS) |
| `remember` | Store URLs in browser memory for later recall |
| `install` | First-time setup |
| `daemon` | Manage the background service |
