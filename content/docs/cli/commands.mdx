## Global options

All commands support:

- `--json` — emit machine-readable JSON to stdout
- `--verbose`, `-v` — verbose stderr logging
- `--version` — print version and exit

Set `OMNISCOUT_JSON=1` in the environment to make JSON output the default. See [Configuration](/docs/cli/configuration) for the full JSON contract and every environment variable.

Full guide: [Browser automation](/docs/cli/browser).

| Command | What it does |
|---------|--------------|

| `browser snapshot [--refs-only]` | Interactive elements with `@eN` refs (`--overlay` to visualize) |

| `browser click <ref>` | Click (`--button`, `--clicks`, `--mod`, `--coord`) |
| `browser fill <ref> <value>` | Replace field content |
| `browser type <ref> <text>` | Append text (`--delay-ms`) |
| `browser paste <ref> <text>` | Insert at cursor |
| `browser select <ref> <option>` | Native `<select>` |
| `browser scroll [up\|down]` | Scroll page/element (`--amount`, `--ref`) |
| `browser key <combo>` | Keyboard shortcut (`Enter`, `cmd+s`, …) |
| `browser hover <ref>` | Mouse over element/coordinate |
| `browser upload <ref> <files>` | Attach files to `<input type=file>` |
| `browser is <ref> <state>` | visible/hidden/enabled/disabled/checked/editable |
| `browser get title/url/text/html` | Read page properties |
| `browser eval <js>` | Run JavaScript, return the value |
| `browser extract-visible` | Visible text, optional `--schema` shaping |
| `browser find-image` | Locate an image template in the viewport |
| `browser screenshot [-o PATH]` | PNG/JPEG (`--full-page`, `--ref`, `--delay`, `--format`) |
| `browser pdf [-o PATH]` | Render to PDF (`--paper`, `--landscape`, `--scale`) |
| `browser wait …` | `text`, `selector`, `networkidle`, `url` (+ `--ms`, `--timeout-ms`) |
| `browser mouse scroll/move` | Raw mouse input at coordinates |

| `browser network start/stop/list/tail/detail` | Request/response capture |

| `browser login <url>` | Headful login, blocks (`--profile`, `--done`, `--success-pattern`) |

## Environment variables

| Variable | Purpose |
|---|---|
| `OMNISCOUT_JSON=1` | Force JSON output on every command |
| `OMNISCOUT_DAEMON_AUTO_START=0` | Don't auto-start the daemon |
| `OMNISCOUT_DAEMON_PORT` | Override the daemon port (default 7720) |
| `OMNISCOUT_DATA_DIR` | Override data dir |
| `OMNISCOUT_BROWSER` | Browser id (overrides config) |
| `OMNISCOUT_EMBED_LOCAL_ONLY=0` | Allow runtime Hugging Face fetches |
| `TWOCAPTCHA_API_KEY` / `CAPTCHA_API_KEY` | CAPTCHA solver key |

Full list with config keys and data layout: [Configuration](/docs/cli/configuration).
