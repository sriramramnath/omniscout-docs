OmniScout는 독립적인 **터미널 네이티브 웹 인터페이스**입니다. AI 에이전트를 위한 로컬 브라우저 브레인으로, 웹을 검색하고 구조화된 데이터를 추출하며 실제 브라우저를 제어하고 데스크톱 앱을 자동화하면서 모든 것을 기억합니다 — 노트북을 떠나지 않습니다.

## 전체 구성

- **CLI** — 직접(또는 에이전트가) 입력하는 `omniscout` 명령어. 모든 명령어는 JSON을 말합니다.
- **Daemon** — `127.0.0.1:7720`의 long-lived 백그라운드 프로세스로 브라우저를 따뜻하게 유지해 동작이 1초 이내에 끝납니다.
- **백엔드** — Patchright(기본값, 격리된 Chromium) 또는 실제 로그인이 있는 기존 브라우저를 구동하는 extension.

전체 그림은 [동작 원리](/docs/cli/architecture)를 참고하세요: `@eN` ref, 세션, 프로필, 동작 히스토리, 이벤트 스트림.

## 설치

```bash
pip install omniscout
omniscout install --skill
```

전체 설정 — 브라우저, daemon, 모델 — 은 [설치](/docs/cli/installation)에서 다룹니다. 5분 투어는 [빠른 시작](/docs/cli/quickstart)입니다.

## 설계 원칙

- **로컬 우선** — 클라우드 계정, API 키, 호스팅 서버가 없습니다. 상태, 임베딩, memory는 기기에 머물고, 외부로 나가는 트래픽은 실행한 검색과 가져온 URL뿐입니다.
- **에이전트 ready** — everywhere `--json`, 안정적인 `@eN` 요소 ref, trace/replay가 가능한 기록된 동작 히스토리, Claude Code·Cursor·Codex·Gemini CLI용 스킬 파일.
- **실제 브라우저** — 내 Chromium, 내 쿠키, 내 extension. 프로필로 한 번 로그인하면 계속 재사용합니다.

## 사용

```bash
# Start the daemon (once)
omniscout daemon start

# Search the web
omniscout answer "what is the capital of france"

# Extract content from a URL
omniscout extract https://example.com

# Control a browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research a topic
omniscout research "AI agents in 2026"

# Build a knowledge graph
omniscout graph "Cursor"
```
