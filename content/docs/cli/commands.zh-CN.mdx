## 全局选项

所有命令均支持：

- `--json` — 向 stdout 输出机器可读的 JSON
- `--verbose`、`-v` — 详细 stderr 日志
- `--version` — 打印版本并退出

在环境中设置 `OMNISCOUT_JSON=1` 可将 JSON 输出设为默认。完整 JSON 约定与所有环境变量见[配置](/docs/cli/configuration)。

## 浏览器命令

完整指南：[浏览器自动化](/docs/cli/browser)。

| 命令 | 功能 |
|---------|--------------|
| `browser navigate <url>` / `open` | 打开 URL（`--profile`、`--session`、`--new-tab`、`--headful`、`--wait-until`、`--auto-captcha`） |
| `browser back/forward/reload` | 历史导航 |
| `browser snapshot [--refs-only]` | 带 `@eN` ref 的可交互元素（`--overlay` 可视化） |
| `browser observe "<hint>"` | 为自然语言指令查找候选 ref |
| `browser act "<instruction>"` | 解析并执行页面操作（`--value`、`--dry-run`） |
| `browser click <ref>` | 点击（`--button`、`--clicks`、`--mod`、`--coord`） |
| `browser fill <ref> <value>` | 替换字段内容 |
| `browser type <ref> <text>` | 追加文本（`--delay-ms`） |
| `browser paste <ref> <text>` | 在光标处插入 |
| `browser select <ref> <option>` | 原生 `<select>` |
| `browser scroll [up\|down]` | 滚动页面 / 元素（`--amount`、`--ref`） |
| `browser key <combo>` | 键盘快捷键（`Enter`、`cmd+s`……） |
| `browser hover <ref>` | 鼠标悬停于元素 / 坐标 |
| `browser upload <ref> <files>` | 为 `<input type=file>` 附加文件 |
| `browser is <ref> <state>` | visible / hidden / enabled / disabled / checked / editable |
| `browser get title/url/text/html` | 读取页面属性 |
| `browser eval <js>` | 运行 JavaScript 并返回值 |
| `browser extract-visible` | 可见文本，可选 `--schema` 整形 |
| `browser find-image` | 在视口中定位图片模板 |
| `browser screenshot [-o PATH]` | PNG / JPEG（`--full-page`、`--ref`、`--delay`、`--format`） |
| `browser pdf [-o PATH]` | 渲染为 PDF（`--paper`、`--landscape`、`--scale`） |
| `browser wait …` | `text`、`selector`、`networkidle`、`url`（+ `--ms`、`--timeout-ms`） |
| `browser mouse scroll/move` | 坐标级的原始鼠标输入 |
| `browser tab list/close/switch` | 会话内的标签页管理 |
| `browser network start/stop/list/tail/detail` | 请求 / 响应捕获 |
| `browser console start/stop/list/tail` | 控制台 + JS 错误捕获 |
| `browser login <url>` | 有界面登录，会阻塞（`--profile`、`--done`、`--success-pattern`） |
| `browser captcha` | 检测 / 求解（`none\|2captcha\|capsolver\|manual`、`--detect-only`） |
| `browser close [--all]` | 关闭单个会话或全部 |

## 环境变量

| 变量 | 用途 |
|---|---|
| `OMNISCOUT_JSON=1` | 强制每条命令输出 JSON |
| `OMNISCOUT_DAEMON_AUTO_START=0` | 不自动启动 daemon |
| `OMNISCOUT_DAEMON_PORT` | 覆盖 daemon 端口（默认 7720） |
| `OMNISCOUT_DATA_DIR` | 覆盖数据目录 |
| `OMNISCOUT_BROWSER` | 浏览器 id（覆盖配置） |
| `OMNISCOUT_EMBED_LOCAL_ONLY=0` | 允许运行时从 Hugging Face 获取 |
| `TWOCAPTCHA_API_KEY` / `CAPTCHA_API_KEY` | 验证码求解器 key |

完整列表（含配置键与数据布局）：[配置](/docs/cli/configuration)。
