OmniScout — это автономный, **терминальный интерфейс для веба**: локальный мозг браузера для ИИ-агентов. Он ищет в вебе, извлекает структурированные данные, управляет настоящим браузером, автоматизирует десктопные приложения и всё запоминает — не покидая ваш ноутбук.

## Как это складывается

- **CLI** — команда `omniscout`, которую вводите вы (или ваш агент). Каждая команда говорит на JSON.
- **Daemon** — долгоживущий фоновый процесс на `127.0.0.1:7720`, который держит браузер тёплым, поэтому действия субсекундны.
- **Бэкенды** — Patchright (по умолчанию, изолированный Chromium) или расширение, управляющее вашим существующим браузером с вашими реальными входами.

См. [Как это работает](/docs/cli/architecture) для полной картины: `@eN` refs, сессии, профили, история действий и поток событий.

## Установка

```bash
pip install omniscout
omniscout install --skill
```

Полная настройка — браузеры, daemon, модели — описана в [Установка](/docs/cli/installation). Тур за 5 минут — [Быстрый старт](/docs/cli/quickstart).

## Принципы дизайна

- **Local-first** — без облачного аккаунта, API-ключа или хостинг-сервера. Состояние, эмбеддинги и память остаются на вашей машине; единственный исходящий трафик — выполняемые вами поиски и загружаемые URL.
- **Готовность к агентам** — `--json` везде, стабильные `@eN` refs элементов, записанная история действий с trace/replay и файлы skills для Claude Code, Cursor, Codex и Gemini CLI.
- **Настоящий браузер** — ваш Chromium, ваши cookies, ваши расширения. Войдите один раз с профилем, переиспользуйте вечно.

## Использование

```bash
# Start the daemon (once)
omniscout daemon start

# Search the web
omniscout answer "what is the capital of france"

# Extract content from a URL
omniscout extract https://example.com

# Control a browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research a topic
omniscout research "AI agents in 2026"

# Build a knowledge graph
omniscout graph "Cursor"
```
