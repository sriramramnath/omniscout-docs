OmniScout has three parts:

1. **CLI** — the `omniscout` command you type
2. **Daemon** — a long-lived background process that holds the browser open
3. **Backends** — Playwright (default) or Chrome extension

```mermaid

  CLI["CLI — omniscout command"] -->|"HTTP POST"| Daemon["Daemon — background process"]
  Daemon --> Playwright["Playwright (default)"]
  Daemon --> Extension["Chrome extension (opt-in)"]
  Playwright --> Browser["Browser"]
  Extension --> Browser
```

## Key concepts

### `@eN` refs

When you run `snapshot`, OmniScout returns the page's accessibility tree with stable element refs (`@e1`, `@e2`, ...). Use these to click, fill, or interact — they survive CSS changes.

### Daemon

The daemon keeps Playwright warm so every action is sub-second. Start it once with `omniscout daemon start`.

### Backends

- **Playwright** (default): OmniScout launches its own Chrome with a persistent profile
- **Chrome extension** (opt-in): Drives your real Chrome with your real logins

### Profiles

Persistent browser profiles store cookies and login state. Create one with `omniscout profile create work`, then use `--profile work` on every command.

## Data location

| Platform | Path |
|---|---|
| macOS | `~/Library/Application Support/omniscout/` |
| Linux | `~/.local/share/omniscout/` |

Override with `OMNISCOUT_DATA_DIR`.
