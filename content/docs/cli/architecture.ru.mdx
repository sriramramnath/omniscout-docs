OmniScout состоит из трёх частей:

1. **CLI** — команда `omniscout`, которую вы вводите
2. **Daemon** — долгоживущий фоновый процесс, удерживающий браузер открытым
3. **Бэкенды** — Playwright (по умолчанию) или расширение Chrome

```mermaid

  CLI["CLI — omniscout command"] -->|"HTTP POST"| Daemon["Daemon — background process"]
  Daemon --> Playwright["Playwright (default)"]
  Daemon --> Extension["Chrome extension (opt-in)"]
  Playwright --> Browser["Browser"]
  Extension --> Browser
```

## Ключевые понятия

### Ссылки `@eN`

При выполнении `snapshot` OmniScout возвращает accessibility-дерево страницы со стабильными ссылками на элементы (`@e1`, `@e2`, ...). Используйте их для кликов, заполнения или взаимодействия — они устойчивы к изменениям CSS.

### Демон

Демон держит Playwright в готовности, поэтому каждое действие занимает доли секунды. Запустите его один раз командой `omniscout daemon start`.

### Бэкенды

- **Playwright** (по умолчанию): OmniScout запускает собственный Chrome с постоянным профилем
- **Расширение Chrome** (опционально): управляет вашим настоящим Chrome с вашими настоящими входами

### Профили

Постоянные профили браузера хранят cookies и состояние входа. Создайте профиль командой `omniscout profile create work`, затем используйте `--profile work` в каждой команде.

## Расположение данных

| Платформа | Путь |
|---|---|
| macOS | `~/Library/Application Support/omniscout/` |
| Linux | `~/.local/share/omniscout/` |

Переопределяется через `OMNISCOUT_DATA_DIR`.
