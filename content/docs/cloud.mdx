OmniScout Cloud is the hosted API for semantic search, grounded answers, and remote browser/computer sessions. It uses the same retrieval and reranking pipeline as the local CLI, backed by an owned Qdrant index instead of DuckDuckGo.

## What you get

| Capability | Endpoint | Description |
|---|---|---|
| **Search** | `POST /v0/search` | Hybrid vector + BM25 retrieval over the owned index, reranked with omniscout |
| **Answer** | `POST /v0/answer` | Search → extract → AI synthesis with sources and confidence |
| **Browser sessions** | `POST /v0/browser/sessions` | Lightweight browser-only Sprite (`capabilities: ["browser"]`) |
| **Computer sessions** | `POST /v0/computer/sessions` | Unified Sprite with browser + desktop (`capabilities: ["browser", "computer"]`) |
| **Session files** | `POST/GET /v0/sessions/{id}/files` | Upload to or download from a Sprite |

### What changed for session callers

`POST /v0/search` and `POST /v0/answer` are **unchanged**.

Session endpoints use the same paths as before, with these differences:

1. **Save `session_secret`** from the create response — required on every command and file request via `x-session-secret`.
2. **Computer sessions are unified** — one `session_id` supports both browser commands (`POST /v0/browser/sessions/{id}`) and computer commands (`POST /v0/computer/sessions/{id}`). You no longer need a separate browser session when you already have a computer session.
3. **Action names** — browser actions use bare names (`navigate`, `screenshot`); computer actions use the `computer.` prefix (`computer.type`, `computer.screenshot`).
4. **File routes are new** — use `/v0/sessions/{id}/files` to upload files or download screenshots/PDFs from the Sprite.
5. **Expiry is inactivity-based** — sessions extend on each command (default 30 min idle, 2 hr max). Do not assume a fixed TTL from create time.

```bash
# 1. Create unified computer session (API key only)
curl -X POST https://api.omniscout.xyz/v0/computer/sessions \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY"

# Response includes session_id, session_secret, capabilities: ["browser","computer"]

# 2. Browser command on the same session (both headers)
curl -X POST "https://api.omniscout.xyz/v0/browser/sessions/$SESSION_ID" \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "x-session-secret: $SESSION_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"action":"navigate","args":{"url":"https://example.com"}}'

# 3. Computer command on the same session
curl -X POST "https://api.omniscout.xyz/v0/computer/sessions/$SESSION_ID" \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "x-session-secret: $SESSION_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"action":"computer.type","args":{"text":"hello"}}'
```

## Quick start

1. Sign up at [api.omniscout.xyz](https://api.omniscout.xyz) (or your deployment URL).
2. Create an API key in the dashboard — keys start with `os_live_`.
3. Send your first request:

```bash
curl -X POST https://api.omniscout.xyz/v0/search \
  -H "Authorization: Bearer os_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "rust async runtimes", "limit": 10}'
```

## CLI vs Cloud

| | **CLI** | **Cloud API** |
|---|---|---|
| Search source | DuckDuckGo + local rerank | Owned Qdrant index + omniscout rerank |
| Answers | Local Probe Zero Mini | Vercel AI Gateway (configurable model) |
| Browser | Your local Chrome / Playwright | Fly Sprites with omniscout daemon |
| Auth | None (runs locally) | Bearer API key (`os_live_...`) |
| Billing | Free, open source | Free tier + paid plans |

The local CLI is unchanged. Cloud is additive — use whichever fits your deployment.

## Architecture

```
Client → Vercel gateway (/v0/*) → Fly search worker → Qdrant Cloud
                                 → Vercel AI Gateway (answers)
                                 → Fly Sprites (browser/computer)
```

- **Vercel** hosts the dashboard, API gateway, Clerk auth, and Convex (keys, usage, sessions).
- **Fly.io** runs the search worker, indexer, and Sprites.
- **Qdrant Cloud** stores the owned search index (Common Crawl + StormCrawler, additive ingest).
