OmniScout Cloud는 호스팅 API입니다: owned 인덱스에 대한 의미 검색, 근거 있는 답변, Fly Sprite 위 원격 브라우저/컴퓨터 세션. 로컬 CLI는 그대로입니다 — Cloud는 추가분입니다.

## 1. API 키 받기

1. [api.omniscout.xyz](https://api.omniscout.xyz)에서 로그인합니다.
2. **Dashboard → API Keys** → **Create key**로 이동합니다. 값을 복사하세요 — `os_live_`로 시작하며 한 번만 표시됩니다.
3. export합니다:

```bash
export OMNISCOUT_API_KEY=os_live_YOUR_KEY
export OMNISCOUT_BASE_URL=https://api.omniscout.xyz
```

키 동작 방식과 두 번째 자격 증명(세션 secret): [인증](/docs/authentication).

## 2. 첫 검색

```bash
curl -X POST $OMNISCOUT_BASE_URL/v0/search \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "rust async runtimes", "limit": 5}'
```

`url`, `title`, `snippet`, `score`, `rank`가 있는 랭크된 히트와 지원용 `request_id`를 받습니다. [엔드포인트](/docs/endpoints#post-v0search)를 참고하세요.

## 3. 첫 답변

```bash
curl -X POST $OMNISCOUT_BASE_URL/v0/answer \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "What is the latest stable Rust version?"}'
```

`source`와 `confidence`가 있는 `answer`를 받습니다 — 근거가 빈약하면 답변이 null인 `status: insufficient_information`이 옵니다. [엔드포인트](/docs/endpoints#post-v0answer)를 참고하세요.

## 4. 첫 브라우저 세션

세션은 CLI와 같은 daemon primitive를 원격 Sprite에서 실행합니다. 생명주기: **생성 → 폴링 → 동작 → 삭제**.

```bash
# Create (API key only) — save session_id AND session_secret
CREATE=$(curl -sS -X POST $OMNISCOUT_BASE_URL/v0/sessions \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"computer"}')

SESSION_ID=$(echo "$CREATE" | jq -r .session_id)
SESSION_SECRET=$(echo "$CREATE" | jq -r .session_secret)

# Poll until ready
curl -sS $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" | jq .status

# Act (API key + session secret)
curl -sS -X POST $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID/actions \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" \
  -H "x-session-secret: $SESSION_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"action":"navigate","args":{"url":"https://example.com"}}'

# Destroy (API key only)
curl -sS -X DELETE $OMNISCOUT_BASE_URL/v0/sessions/$SESSION_ID \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY"
```

타입: `"browser"`는 가벼운 브라우저 전용 Sprite, `"computer"`는 통합형(하나의 세션 id에 브라우저 + 데스크톱)입니다. 세션은 비활성 후 만료됩니다(기본 30분, 최대 2시간) — 명령어마다 윈도우가 연장됩니다.

SDK를 선호하시나요? Python과 TypeScript의 같은 흐름은 [SDK](/docs/sdks)를 참고하세요.

## 5. 사용량 확인

```bash
curl -sS $OMNISCOUT_BASE_URL/v0/usage \
  -H "Authorization: Bearer $OMNISCOUT_API_KEY" | jq .
```

과금은 사용량 기반으로만 부과됩니다 (인프라 비용 × 1.30) — [사용량 및 결제](/docs/billing)를 참고하세요.
