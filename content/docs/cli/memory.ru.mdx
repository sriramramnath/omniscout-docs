Память браузера — это локальный векторный индекс по посещённым страницам и написанным заметкам. Сохраняйте сейчас, вспоминайте семантически позже — без вызовов LLM.

## Запомнить страницу

```bash
omniscout remember https://example.com/blog/post
```

`remember` посещает URL, извлекает его контент и сохраняет в `memory.sqlite`. Позже ищите по нему командой `memory`:

```bash
omniscout memory "neural networks in production"
```

`memory` ранжирует сохранённые страницы по семантической близости к запросу, поэтому совпадают и перефразировки — точное название или URL не нужны.

## Сначала ищите в собственной памяти

Команда `search` может целиться в память вместо веба:

```bash
omniscout search "query" --source memory
```

Полезно в агентах: проверьте уже увиденное (`--source memory`), прежде чем тратить время на свежий веб-поиск.

## Управление корпусом

`memory` — это группа команд, а не просто запрос:

```bash
omniscout memory "query"     # semantic search over remembered pages
omniscout memory list        # list records
omniscout memory show <id>   # show one record
omniscout memory note "idea: compare rerankers"   # standalone note
omniscout memory delete <id> # delete records
omniscout memory stats        # corpus statistics
omniscout memory clear        # wipe the entire corpus
```

Привяжите заметку к активной странице (или напишите отдельную) командой `memory note` — заметки тоже индексируются, поэтому решения и контекст всплывают в later searches.

## Локальный индекс

Связанные команды локального индекса:

```bash
omniscout index ...          # manage the local search index (re-index, query cache)
omniscout crawl ...          # run and inspect local crawl jobs
omniscout extract-jobs ...   # inspect background extract jobs
```

Память (`memory.sqlite`), векторный индекс (`qdrant/`) и кэш страниц (`cache/pages/`) живут в data dir — см. [Конфигурация](/docs/cli/configuration). Они никогда не покидают вашу машину; единственный исходящий трафик — выполняемые вами поиски и загружаемые URL.
