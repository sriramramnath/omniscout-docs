AIエージェント向けのローカルファーストなブラウザ操作、意味検索、リサーチです。クラウドアカウントもAPIキーも不要 — インストールしてすぐ使えます。

## インストール

```bash
pip install omniscout
omniscout install --skill
```

完全なセットアップ：[インストール](/docs/installation)。5分ツアー：[クイックスタート](/docs/quickstart)。

## 使い方

```bash
omniscout daemon start

# Search
omniscout answer "what is the capital of france"

# Extract
omniscout extract https://example.com

# Browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research
omniscout research "AI agents in 2026"

# Knowledge graph
omniscout graph "Cursor"
```

## 同梱内容

| コマンド | 内容 | ガイド |
|---|---|---|
| `omniscout answer`／`search` | 引用付き直接Q&A／ランク付きヒットです | [検索](/docs/search/search) |
| `omniscout extract` | URLを取得してクリーンなコンテンツを返します | [抽出](/docs/search/extraction) |
| `omniscout research`／`graph` | マルチステップパイプライン／ナレッジグラフです | [リサーチ](/docs/search/research) |
| `omniscout browser` | ブラウザを操作します | [ブラウザ](/docs/automation/browser) |
| `omniscout computer` | デスクトップ自動化です（macOS） | [コンピューター](/docs/automation/computer) |
| `omniscout daemon`／`session`／`profile` | バックグラウンドサービス、セッション、プロファイルです | [セッション](/docs/automation/sessions) |
| `omniscout remember`／`memory` | ページを保存・呼び出しします | [メモリ](/docs/search/memory) |
| `omniscout record`／`macro`／`monitor` | 再利用可能フロー、変更アラートです | [ワークフロー](/docs/automation/workflows) |

## ローカルファースト

クラウドアカウント、APIキー、ホストサーバーは不要です。外部送信はDuckDuckGo検索と明示的に取得したURLのみです。
