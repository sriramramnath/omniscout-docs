OmniScout может управлять нативными приложениями macOS, окнами, буфером обмена и экраном.

## Команды

| Команда | Что делает |
|---------|--------------|
| `computer navigate <target>` | Открытие приложения, файла или URL |
| `computer type <text>` | Ввод в активное окно |
| `computer key <combo>` | Отправка сочетания клавиш (например, `cmd+v`) |
| `computer screenshot` | Снимок экрана |
| `computer clipboard get` | Чтение буфера обмена |
| `computer clipboard set <text>` | Запись в буфер обмена |
| `computer window list` | Список открытых окон |
| `computer window activate <title>` | Вывод окна на передний план |
| `computer window close <title>` | Закрытие окна |
| `computer wait <ms>` | Пауза в миллисекундах |

## Взаимодействие с элементами интерфейса

| Команда | Что делает |
|---------|--------------|
| `computer ui snapshot` | Получение ссылок на элементы интерфейса |
| `computer ui click <ref>` | Клик по элементу интерфейса |
| `computer ui drag <src> <dst>` | Перетаскивание между элементами |
| `computer ui is <ref> <role>` | Проверка соответствия элемента роли |

## Пример

```bash
# Открытие Notes и ввод сообщения
omniscout computer navigate "Notes" --session notes
omniscout computer type "Hello from OmniScout!" --session notes
omniscout computer screenshot --out /tmp/notes.png --session notes
```

См. `omniscout computer --help` для всех опций.
