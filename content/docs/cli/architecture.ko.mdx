OmniScout는 세 부분으로 구성됩니다:

1. **CLI** — 직접 입력하는 `omniscout` 명령어
2. **데몬** — 브라우저를 열어 두는 오래 실행되는 백그라운드 프로세스
3. **백엔드** — Playwright (기본값) 또는 Chrome 확장 프로그램

```mermaid
flowchart LR
  CLI["CLI — omniscout command"] -->|"HTTP POST"| Daemon["Daemon — background process"]
  Daemon --> Playwright["Playwright (default)"]
  Daemon --> Extension["Chrome extension (opt-in)"]
  Playwright --> Browser["Browser"]
  Extension --> Browser
```

## 핵심 개념

### `@eN` 참조

`snapshot`을 실행하면 OmniScout는 안정적인 요소 참조(`@e1`, `@e2`, …)가 포함된 페이지 접근성 트리를 반환합니다. 이를 사용해 클릭, 입력, 상호작용하세요 — CSS가 변경되어도 유지됩니다.

### 데몬

데몬은 Playwright를 웜 상태로 유지해 모든 동작이 1초 이내에 실행됩니다. `omniscout daemon start`로 한 번 시작하세요.

### 백엔드

- **Playwright** (기본값): OmniScout가 영구 프로필로 자체 Chrome을 실행
- **Chrome 확장 프로그램** (선택): 실제 로그인이 있는 실제 Chrome을 구동

### 프로필

영구 브라우저 프로필은 쿠키와 로그인 상태를 저장합니다. `omniscout profile create work`로 생성한 뒤, 모든 명령어에 `--profile work`를 사용하세요.

## 데이터 위치

| 플랫폼 | 경로 |
|---|---|
| macOS | `~/Library/Application Support/omniscout/` |
| Linux | `~/.local/share/omniscout/` |

`OMNISCOUT_DATA_DIR`로 재정의할 수 있습니다.
