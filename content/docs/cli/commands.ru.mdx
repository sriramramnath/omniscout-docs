Используйте `omniscout --help`, чтобы увидеть все команды, или `omniscout <command> --help` для опций.

## Команды верхнего уровня

| Команда | Что делает | Когда использовать |
|---------|--------------|-------------|
| `search` | Веб-поиск с опциональным семантическим реранжированием | Быстрый поиск URL или фактов |
| `answer` | Получение веб-результатов и синтез с помощью LLM | Прямые вопросы-ответы с цитатой. Предпочтительнее, чем `search` |
| `map` | Обход сайта и построение карты URL | Исследование целого домена |
| `warmup` | Предзагрузка эмбеддинг-моделей и моделей ответов в демоне | Снижение задержки первых вызовов |
| `remember` | Посещение URL, извлечение контента, сохранение в памяти браузера | Сохранение информации для последующего использования |
| `extract` | Загрузка URL или запроса с возвратом читаемых/структурированных данных | Получение сырого текста или JSON со страницы |
| `open` | Открытие URL или последнего индекса результатов поиска в управляемом браузере | Запуск страницы в контролируемом Chromium |
| `snapshot` | Снятие accessibility-снимка с `@e`-ссылками | Просмотр структуры страницы для последующих UI-действий |
| `context` | Показ текущего состояния непрерывности рабочего процесса | Отладка или продолжение многошагового процесса |
| `reset` | Сброс состояния непрерывности | Начало новой сессии |
| `auto` | Автоматическая маршрутизация ввода к лучшей команде | Простое использование в одну строку |
| `research` | Многошаговый процесс: search → crawl → extract → rerank → summarize | Полные исследовательские пайплайны |
| `graph` | Построение структурированного графа знаний для сущности | Организация фактов в узлы/рёбра |
| `install` | Проверка (или загрузка) браузера Chromium для автоматизации | Первоначальная настройка |
| `settings` | Просмотр / изменение пользовательских настроек | Настройка конфигурации |
| `browser` | Прямая автоматизация Chromium на основе Playwright | Сложные рабочие процессы веб-интерфейса |
| `computer` | Нативная автоматизация рабочего стола (macOS) | Взаимодействие с приложениями ОС, файлами, буфером обмена и т.д. |
| `daemon` | Управление долгоживущим демоном управления браузером | Запуск/остановка фонового сервиса |
| `index` | Управление локальным поисковым индексом | Переиндексация или запрос локального кэша |
| `crawl` | Запуск / просмотр локальных задач обхода | Массовый обход сайтов |
| `record` | Запись действий демона в именованный макрос | Создание переиспользуемых скриптов |
| `macro` | Список / запуск сохранённых макросов | Повтор записанных действий |
| `replay` | Повтор записанных действий браузера | Отладка или повтор процесса |
| `workflow` | Экспорт / просмотр рабочего процесса непрерывности | Сохранение или совместное использование процесса |
| `monitor` | Непрерывный мониторинг URL на изменения | Уведомление об обновлениях контента |
| `profile` | Управление постоянными профилями браузера | Разделение контекстов (рабочий и личный) |
| `session` | Управление долгоживущими сессиями браузера | Сохранение cookies/входов между запусками |
| `memory` | Память браузера — запомненные визиты и заметки | Получение сохранённых фрагментов |

## Глобальные опции

Все команды поддерживают:

- `--json` — вывод машиночитаемого JSON в stdout
- `--verbose`, `-v` — подробное логирование в stderr
- `--version` — вывод версии и выход

Установите `OMNISCOUT_JSON=1` в окружении, чтобы сделать вывод JSON по умолчанию.

## Команды браузера

| Команда | Что делает |
|---------|--------------|
| `browser navigate <url>` | Открытие URL в активной вкладке |
| `browser snapshot --refs-only` | Получение интерактивных элементов с `@eN`-ссылками |
| `browser click <ref>` | Клик по элементу по `@eN`-ссылке |
| `browser fill <ref> <value>` | Заполнение поля формы |
| `browser type <ref> <text>` | Ввод текста в поле |
| `browser scroll [up\|down]` | Прокрутка страницы |
| `browser key <combo>` | Нажатие сочетания клавиш |
| `browser screenshot [-o PATH]` | Создание скриншота |
| `browser pdf [-o PATH]` | Генерация PDF |
| `browser wait text <substring>` | Ожидание появления текста |
| `browser login <url>` | Открытие видимого окна входа |
| `browser captcha` | Обнаружение или решение CAPTCHA |
| `browser close --all` | Закрытие всех сессий |

## Команды компьютера (macOS)

| Команда | Что делает |
|---------|--------------|
| `computer navigate <target>` | Открытие приложения, файла или URL |
| `computer type <text>` | Ввод в активное окно |
| `computer key <combo>` | Отправка сочетания клавиш |
| `computer screenshot` | Снимок экрана |
| `computer clipboard get` | Чтение буфера обмена |
| `computer clipboard set <text>` | Запись в буфер обмена |
| `computer window list` | Список открытых окон |
| `computer window activate <title>` | Вывод окна на передний план |
| `computer ui snapshot` | Получение ссылок на элементы интерфейса |
| `computer ui click <ref>` | Клик по элементу интерфейса |

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `OMNISCOUT_JSON=1` | Принудительный вывод JSON для каждой команды |
| `OMNISCOUT_DAEMON_AUTO_START=0` | Отключение автозапуска демона |
| `OMNISCOUT_DAEMON_PORT` | Переопределение порта демона (по умолчанию 7720) |
| `OMNISCOUT_DATA_DIR` | Переопределение каталога данных |
