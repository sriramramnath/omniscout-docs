`omniscout computer`는 네이티브 macOS 애플리케이션, 창, 클립보드, 화면을 제어합니다 — [브라우저 자동화](/docs/automation/browser)의 데스크톱 counterpart입니다. 명령어는 같은 daemon JSON envelope와 `--session` 모델을 사용합니다.

먼저 지원 여부를 확인하세요: `omniscout computer doctor`로 환경을 진단하고, `omniscout computer backend`로 사용 가능한 백엔드를 나열합니다. 데스크톱 자동화는 현재 네이티브 `open`, AppleScript, `screencapture`, 클립보드 도구를 통한 macOS를 지원합니다.

## 열기, 입력, 키

```bash
omniscout computer navigate /Applications/Notes.app   # app, file, dir, or URL
omniscout computer navigate "Notes" --session notes
omniscout computer type "Meeting notes" --session notes
omniscout computer key cmd+s
omniscout computer wait 300                            # milliseconds
```

- `navigate`는 OS가 열 수 있는 모든 것을 엽니다: 앱 경로/이름, 파일, 디렉터리, URL.
- `type`은 현재 포커스된 창에 입력하고, `key`는 콤보를 보냅니다(`cmd+s`, `ctrl+c`, `cmd+space`, …).
- `wait`는 고정된 밀리초만큼 쉽니다 — 애니메이션에만 쓰세요. 데스크톱에는 DOM 조건이 없습니다.

## 클립보드 및 스크린샷

```bash
omniscout computer clipboard set "Hello from Scout"
omniscout computer clipboard get
omniscout computer screenshot --out /tmp/desktop.png
```

클립보드 왕복은 데스크톱과 셸(또는 에이전트) 사이에서 텍스트를 옮기는 가장 간단한 방법입니다: set하고 `key cmd+v`로 붙여넣은 뒤 get으로 검증하세요.

## 창

```bash
omniscout computer window list
omniscout computer window activate "Notes"
omniscout computer window close "Notes"
```

먼저 list로 확인하고(제목이 일치해야 합니다) 입력 전에 activate로 포커스하세요.

## UI 요소 상호작용

막연한 입력 대신 요소 단위로 제어하려면 접근성 트리를 snapshot하고 `@eN` ref에 동작하세요 — 브라우저 자동화와 같은 모델입니다:

```bash
omniscout computer ui snapshot
omniscout computer ui click '@e4'
omniscout computer ui drag '@e2' '@e7'
omniscout computer ui is '@e4' button
```

## 전체 예제

```bash
# Open Notes and type a message
omniscout computer navigate "Notes" --session notes
omniscout computer wait 300
omniscout computer type "Hello from OmniScout!" --session notes
omniscout computer key cmd+s
omniscout computer screenshot --out /tmp/notes.png --session notes
```

## Cloud counterpart

OmniScout Cloud에서는 같은 primitive가 통합 세션 위 `computer.*` 액션으로 원격 Sprite에서 실행됩니다 — [엔드포인트](/docs/endpoints#computer-sessions)를 참고하세요.

모든 옵션은 `omniscout computer --help`(그리고 `omniscout computer ui --help`)를 참고하세요.
