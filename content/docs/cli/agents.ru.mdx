OmniScout создан, чтобы им управляли ИИ-агенты: каждая команда говорит на JSON, refs элементов стабильны, а вся история действий доступна для inspect. Вот как всё настроить.

## 1. Установка

```bash
pip install omniscout
omniscout install --skill
```

Флаг `--skill` копирует инструкции в каталог skills вашего агента:

| Агент | Расположение |
|---|---|
| Claude Code | `~/.claude/skills/scout/SKILL.md` |
| Cursor | `~/.cursor/skills-cursor/scout/SKILL.md` |
| Codex CLI | `~/.codex/skills/scout/SKILL.md` |
| Gemini CLI / Antigravity | `~/.gemini/config/skills/scout/SKILL.md` |

Агент подхватит их автоматически при следующей сессии. Другие агенты (Pi, OpenCode, Windsurf, Cline, Copilot Agent Mode, любой ассистент с шеллом) могут вставить bundled `SKILL.md` в системный промпт.

## 2. Запуск daemon

```bash
omniscout daemon start
```

## 3. Используйте JSON везде

Установите `OMNISCOUT_JSON=1` в начале цикла (или передавайте `--json` в каждом вызове). `stdout` становится структурированным payload; логи идут в `stderr`:

```bash
export OMNISCOUT_JSON=1
omniscout search "robotics simulators"
omniscout browser snapshot | jq '.refs[] | select(.role == "button")'
```

Формы — это Pydantic-контракты (`models.py`) — стабильные поля, на которые может положиться ваш парсер. Каждый ответ несёт достаточно контекста (refs, urls, ids) для следующего вызова.

## 4. Готовый промпт

### Исследование вопроса

```text
Use OmniScout to research "state of open-source browser agents in 2026" and summarize the top 5 passages with their source URLs.
```

### Навигация и клик

```text
Open https://news.ycombinator.com using OmniScout, snapshot interactive elements, click the top story, and screenshot the result to /tmp/hn-top.png.
```

### Одноразовый вход и повторное использование

```text
Run `omniscout browser login https://github.com --profile work`, pause for me to authenticate, then screenshot my notifications page with that profile.
```

### Построение графа знаний

```text
Build a knowledge graph for "Cursor" with OmniScout. Run `omniscout graph "Cursor" --json --data`, show the tree, and cite sources.
```

### Заполнение формы

```text
Use OmniScout to open https://duckduckgo.com, fill the search box with "local-first AI agents", press Enter, wait for results, and list the top 5 results.
```

### Захват сетевого трафика

```text
Open the Vercel pricing page with OmniScout, capture network traffic while scrolling, then list requests matching stripe|payment|checkout.
```

## Цикл агента

Надёжный цикл выглядит так:

1. `daemon start` (идемпотентно — безопасно запускать каждую сессию).
2. `export OMNISCOUT_JSON=1`.
3. Действие: `navigate` → `snapshot --refs-only` → `click/fill` → повторный snapshot.
4. Наблюдение: `screenshot`, `get text`, `network tail`, `console tail`.
5. Очистка: `browser close --all`.

Изолируйте параллельные задачи флагом `--session <name>`, чтобы их вкладки и refs не сталкивались.

## Отладка запусков агента

- `omniscout daemon trace` — inspect JSONL-историю последних 10k действий (что реально сделал агент?).
- `omniscout daemon replay` / `omniscout replay …` — повтор записанного процесса для воспроизведения сбоя.
- `omniscout daemon watch` — живой поток событий, пока агент работает.
- `omniscout context` — показать текущее состояние непрерывности workflow; `omniscout reset` для старта с нуля.

## Виды ошибок

Ожидайте и обрабатывайте такие:

| Сбой | Сигнал | Исправление |
|---|---|---|
| Устаревший `@eN` ref | "ref not found" | Повторный snapshot, используйте новый ref |
| Страница не загружена | Пустой скриншот / нет текста | Сначала `browser wait text/networkidle` |
| Вход протух | Редирект на страницу входа | Повторите `browser login --profile …` |
| CAPTCHA | Обнаружен challenge | Решите вручную или `--solver 2captcha` |
| Daemon не работает | Connection refused | `daemon start` (или проверьте `--port`) |
| Нет результатов | Пустые попадания | Более узкий запрос, другой `--source` |

Полный список: [Устранение неполадок](/docs/cli/troubleshooting).

## Советы для агентов

- Установите `OMNISCOUT_JSON=1` в начале для структурированного вывода.
- Используйте `omniscout browser snapshot --refs-only` для поиска элементов, затем кликайте по `@eN` ref.
- Делайте повторный snapshot после каждого `navigate` — refs устаревают.
- Предпочитайте `wait text/networkidle` фиксированным паузам.
- Записывайте повторяемые процессы через `record`/`macro run` вместо повторной импровизации.
- Закрывайте сессии командой `omniscout browser close --all` по завершении.
