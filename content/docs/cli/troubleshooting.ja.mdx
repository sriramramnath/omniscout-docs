## `@eN`参照が見つからない

前回の`snapshot`以降にページが変化しています。再スナップショットを取って新しい参照を使ってください：

```bash
omniscout browser snapshot --refs-only
omniscout browser click '@e7'
```

## ログインが完了しない

別のシェルから`--done`シグナルを送ってください：

```bash
# ターミナルA：
omniscout browser login https://app.example.com --profile work

# ターミナルB（ログイン後）：
omniscout browser login --done
```

## CAPTCHAで止まる

ヘッドフルウィンドウで解決するか、サードパーティのソルバーを使ってください：

```bash
export TWOCAPTCHA_API_KEY=...
omniscout browser captcha --solver 2captcha
```

## 拡張機能が`backend_unavailable`と表示する

1. `chrome://extensions`を開く — 拡張機能が読み込まれていることを確認
2. 拡張機能アイコンをクリック — 切断時は再接続
3. または`--backend extension`を外してPlaywrightを使う

## Pythonバージョンエラー

```bash
python --version  # 3.11以降が必要
pip install omniscout
```

## Chromeが見つからない

```bash
omniscout settings browsers          # インストール済みを確認
omniscout settings set browser edge  # またはbrave、vivaldiなど
```

## デーモンが起動しない

```bash
omniscout daemon stop
omniscout daemon start
lsof -i :7720                       # ポート使用中か確認
omniscout daemon start --port 7721   # 別ポートを使う
```

## 検索結果が0件

```bash
omniscout search "more specific query"
omniscout search "query" --source ddg
```

## スクリーンショットが真っ白

```bash
# 読み込みを待つ
omniscout browser screenshot https://example.com --delay 3 --out /tmp/page.png

# フルページ
omniscout browser screenshot https://example.com --full-length --out /tmp/full.png
```

## よくある質問

**データはクラウドに送信されますか？**
いいえ。外部への通信はDuckDuckGo検索と明示的に取得したURLのみです。1回限りのモデルダウンロードはローカルにキャッシュされます。

**ChromeなしでOmniScoutを使えますか？**
Chromium系ブラウザが必要です。Chrome/Chromiumをインストールするか、`omniscout install --browser custom --browser-executable <path>`でカスタムパスを設定してください。

**アップデート方法は？**
```bash
pip install --upgrade omniscout
```

**すべてのデータを消去するには？**
```bash
rm -rf ~/Library/Application\ Support/omniscout/   # macOS
rm -rf ~/.local/share/omniscout/                   # Linux
```
