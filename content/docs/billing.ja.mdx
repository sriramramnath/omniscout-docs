---
title: 利用量と請求
description: OmniScout Cloudの従量課金、利用上限、Stripeメーター課金。
---

OmniScout Cloudは**従量課金のみ**です。サブスクリプション段階、月次無料時間、プラン別API制限はありません。

## 料金計算式

```
customer_charge = actual_infrastructure_cost × 1.30
```

これは原価に対する**30%の上乗せ**（原価＋30%）であり、30%の粗利率ではありません。

## 課金対象リソース

| リソース | 計測 | Stripeメーターイベント |
|---|---|---|
| コンピューター実行時間 | セッション準備完了 → 破棄までの秒数 | `computer_runtime_seconds` |
| ブラウザ実行時間 | セッション準備完了 → 破棄までの秒数 | `browser_runtime_seconds` |
| 検索 | `POST /v0/search`リクエストごと | `search_requests` |
| 回答 | `POST /v0/answer`リクエストごと | `answer_requests` |

`GET /v0/sessions/{id}`や`POST /v0/sessions/{id}/actions`などのAPI呼び出しはAPI利用量として計測**されません**。不正利用防止、同時実行上限、セッションTTL、利用上限の範囲で無制限です。

## 2層の課金

| 層 | 役割 |
|---|---|
| **Convex利用台帳** | 監査証跡、リアルタイムの料金見積、利用上限の適用 |
| **Stripe Billing** | 支払い方法、メーター利用量、請求書、Customer Portal |

## GET /v0/usage

当期の利用量、見積料金、アクティブセッション、利用上限、請求ステータスを返します。

```json
{
  "period": "2026-09",
  "usage": {
    "computer_runtime_seconds": 3600,
    "browser_runtime_seconds": 1200,
    "search_count": 42,
    "answer_count": 8
  },
  "costs": {
    "underlying_cost_usd": 12.5,
    "markup_multiplier": 1.3,
    "estimated_charge_usd": 16.25
  },
  "spending_limit_usd": 100,
  "spending_limit_remaining_usd": 83.75,
  "billing_status": "active"
}
```

## 利用保護

月次利用上限を超過すると、課金対象操作は`spending_limit_exceeded`付き`402`を返します。`past_due`の請求ステータスのアカウントは、支払い解決までブロックされる場合があります。

## ダッシュボード

利用量と見積料金は[dashboard billing](https://api.omniscout.xyz/dashboard/billing)で確認できます。そのページからStripe Customer Portalを開き、支払い方法と請求書を管理してください。

## セットアップ

運用者はリポジトリ内の`cloud/SETUP.md`に従ってStripeメーター、webhook、原価レートを設定します。
