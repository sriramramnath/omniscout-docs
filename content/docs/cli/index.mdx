Local-first browser control, semantic search, and research for AI agents. No cloud account, no API key — install and go.

## Install

```bash
pip install omniscout
omniscout install --skill
```

Full setup: [Installation](/docs/cli/installation). Five-minute tour: [Quickstart](/docs/cli/quickstart).

## Use

```bash
omniscout daemon start

# Search
omniscout answer "what is the capital of france"

# Extract
omniscout extract https://example.com

# Browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research
omniscout research "AI agents in 2026"

# Knowledge graph
omniscout graph "Cursor"
```

## What's in the box

| Command | What it does | Guide |
|---|---|---|
| `omniscout answer` / `search` | Direct Q&A with citations / ranked hits | [Search](/docs/cli/search) |
| `omniscout extract` | Fetch a URL and return clean content | [Extraction](/docs/cli/extraction) |
| `omniscout research` / `graph` | Multi-step pipeline / knowledge graph | [Research](/docs/cli/research) |
| `omniscout browser` | Control a browser | [Browser](/docs/cli/browser) |
| `omniscout computer` | Desktop automation (macOS) | [Computer](/docs/cli/computer) |
| `omniscout daemon` / `session` / `profile` | Background service, sessions, profiles | [Sessions](/docs/cli/sessions) |
| `omniscout remember` / `memory` | Store and recall pages | [Memory](/docs/cli/memory) |
| `omniscout record` / `macro` / `monitor` | Reusable flows, change alerts | [Workflows](/docs/cli/workflows) |

## Local-first

No cloud account, API key, or hosted server required. The only outbound traffic is DuckDuckGo searches and URLs you explicitly fetch.
