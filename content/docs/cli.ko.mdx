AI 에이전트를 위한 로컬 우선 브라우저 제어, 의미 검색, 리서치. 클라우드 계정도 API 키도 없습니다 — 설치하고 바로 시작하세요.

## 설치

```bash
pip install omniscout
omniscout install --skill
```

전체 설정: [설치](/docs/installation). 5분 투어: [빠른 시작](/docs/quickstart).

## 사용

```bash
omniscout daemon start

# Search
omniscout answer "what is the capital of france"

# Extract
omniscout extract https://example.com

# Browser
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# Research
omniscout research "AI agents in 2026"

# Knowledge graph
omniscout graph "Cursor"
```

## 구성품

| 명령어 | 설명 | 가이드 |
|---|---|---|
| `omniscout answer` / `search` | 인용이 있는 직접 Q&A / 랭크된 히트 | [검색](/docs/search/search) |
| `omniscout extract` | URL을 가져와 깨끗한 콘텐츠 반환 | [추출](/docs/search/extraction) |
| `omniscout research` / `graph` | 다단계 파이프라인 / 지식 그래프 | [리서치](/docs/search/research) |
| `omniscout browser` | 브라우저 제어 | [브라우저](/docs/automation/browser) |
| `omniscout computer` | 데스크톱 자동화 (macOS) | [컴퓨터](/docs/automation/computer) |
| `omniscout daemon` / `session` / `profile` | 백그라운드 서비스, 세션, 프로필 | [세션](/docs/automation/sessions) |
| `omniscout remember` / `memory` | 페이지 저장 및 회상 | [메모리](/docs/search/memory) |
| `omniscout record` / `macro` / `monitor` | 재사용 흐름, 변경 알림 | [워크플로](/docs/automation/workflows) |
