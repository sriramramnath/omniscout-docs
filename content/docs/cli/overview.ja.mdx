OmniScoutはAIエージェントに、Web検索、コンテンツ抽出、ブラウザ操作、デスクトップタスクの自動化を提供します — すべてローカルで、クラウドは不要です。

## インストール

```bash
pip install omniscout
omniscout install --skill
```

## 使い方

```bash
# デーモンを起動（一度だけ）
omniscout daemon start

# Webを検索
omniscout answer "what is the capital of france"

# URLからコンテンツを抽出
omniscout extract https://example.com

# ブラウザを操作
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout browser click '@e3'
omniscout browser screenshot --out /tmp/page.png

# トピックをリサーチ
omniscout research "AI agents in 2026"

# ナレッジグラフを構築
omniscout graph "Cursor"
```

## できること

| コマンド | 内容 |
|---------|--------------|
| `search` | セマンティックリランク付きWeb検索（オプション） |
| `answer` | 引用付きの直接Q&A（`search`より推奨） |
| `extract` | URLを取得してクリーンなMarkdownを返す |
| `research` | マルチステップ：検索 → クロール → 抽出 → 要約 |
| `graph` | 構造化ナレッジグラフを構築 |
| `browser` | ブラウザを操作（移動、クリック、入力、スクリーンショット） |
| `computer` | デスクトップ自動化（macOS） |
| `remember` | URLをブラウザメモリに保存して後で呼び出し |
| `install` | 初回セットアップ |
| `daemon` | バックグラウンドサービスを管理 |
