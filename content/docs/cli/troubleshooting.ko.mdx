## `@eN` 참조를 찾을 수 없음

마지막 `snapshot` 이후 페이지가 변경되었습니다. 다시 스냅샷을 찍고 새 참조를 사용하세요:

```bash
omniscout browser snapshot --refs-only
omniscout browser click '@e7'
```

## 로그인이 완료되지 않음

다른 셸에서 `--done` 신호를 사용하세요:

```bash
# 터미널 A:
omniscout browser login https://app.example.com --profile work

# 터미널 B (로그인 후):
omniscout browser login --done
```

## CAPTCHA가 계속 차단됨

직접 보이는 창에서 해결하거나 타사 솔버를 사용하세요:

```bash
export TWOCAPTCHA_API_KEY=...
omniscout browser captcha --solver 2captcha
```

## 확장 프로그램에 `backend_unavailable` 표시

1. `chrome://extensions` 열기 — 확장 프로그램이 로드되었는지 확인
2. 확장 프로그램 아이콘 클릭 — 연결이 끊겼으면 다시 연결
3. 또는 `--backend extension`을 빼고 Playwright 사용

## Python 버전 오류

```bash
python --version  # 3.11+ 필요
pip install omniscout
```

## Chrome을 찾을 수 없음

```bash
omniscout settings browsers          # 설치된 항목 보기
omniscout settings set browser edge  # 또는 brave, vivaldi 등
```

## 데몬이 시작되지 않음

```bash
omniscout daemon stop
omniscout daemon start
lsof -i :7720                       # 포트가 사용 중인지 확인
omniscout daemon start --port 7721   # 다른 포트 사용
```

## 검색 결과가 없음

```bash
omniscout search "more specific query"
omniscout search "query" --source ddg
```

## 스크린샷이 비어 있음

```bash
# 로딩 대기
omniscout browser screenshot https://example.com --delay 3 --out /tmp/page.png

# 전체 페이지
omniscout browser screenshot https://example.com --full-length --out /tmp/full.png
```

## 자주 묻는 질문

**내 데이터가 클라우드로 전송되나요?**
아니요. 유일한 외부 트래픽은 DuckDuckGo 검색과 사용자가 직접 요청한 URL 가져오기뿐입니다. 일회성 모델 다운로드는 로컬에 캐시됩니다.

**Chrome 없이 OmniScout를 사용할 수 있나요?**
Chromium 계열 브라우저가 필요합니다. Chrome/Chromium을 설치하거나 `omniscout install --browser custom --browser-executable <path>`로 사용자 지정 경로를 설정하세요.

**업데이트는 어떻게 하나요?**
```bash
pip install --upgrade omniscout
```

**모든 데이터를 지우려면 어떻게 하나요?**
```bash
rm -rf ~/Library/Application\ Support/omniscout/   # macOS
rm -rf ~/.local/share/omniscout/                   # Linux
```
