## グローバルオプション

すべてのコマンドが対応しています：

- `--json` — 機械可読JSONをstdoutに出力します
- `--verbose`、`-v` — 詳細なstderrログです
- `--version` — バージョンを表示して終了します

環境変数`OMNISCOUT_JSON=1`を設定するとJSON出力がデフォルトになります。完全なJSON契約とすべての環境変数は[設定](/docs/configuration)をご覧ください。

## ブラウザコマンド

完全なガイド：[ブラウザ自動化](/docs/automation/browser)。

| コマンド | 内容 |
|---------|--------------|
| `browser navigate <url>` / `open` | URLを開きます（`--profile`、`--session`、`--new-tab`、`--headful`、`--wait-until`、`--auto-captcha`） |
| `browser back/forward/reload` | 履歴ナビゲーションです |
| `browser snapshot [--refs-only]` | `@eN` ref付きの操作可能要素です（可視化には`--overlay`） |
| `browser observe "<hint>"` | 自然言語指示の候補refを探します |
| `browser act "<instruction>"` | ページ操作を解決＋実行します（`--value`、`--dry-run`） |
| `browser click <ref>` | クリックします（`--button`、`--clicks`、`--mod`、`--coord`） |
| `browser fill <ref> <value>` | フィールド内容を置換します |
| `browser type <ref> <text>` | テキストを追記します（`--delay-ms`） |
| `browser paste <ref> <text>` | カーソル位置に挿入します |
| `browser select <ref> <option>` | ネイティブ`<select>`です |
| `browser scroll [up\|down]` | ページ／要素をスクロールします（`--amount`、`--ref`） |
| `browser key <combo>` | キーボードショートカットです（Enter、`cmd+s`、…） |
| `browser hover <ref>` | 要素／座標にマウスオーバーします |
| `browser upload <ref> <files>` | `<input type=file>`にファイルを添付します |
| `browser is <ref> <state>` | visible／hidden／enabled／disabled／checked／editableです |
| `browser get title/url/text/html` | ページプロパティを読み取ります |
| `browser eval <js>` | JavaScriptを実行して値を返します |
| `browser extract-visible` | 可視テキストです。任意で`--schema`整形できます |
| `browser find-image` | ビューポート内で画像テンプレートを探します |
| `browser screenshot [-o PATH]` | PNG／JPEGです（`--full-page`、`--ref`、`--delay`、`--format`） |
| `browser pdf [-o PATH]` | PDFに描画します（`--paper`、`--landscape`、`--scale`） |
| `browser wait …` | `text`、`selector`、`networkidle`、`url`（`--ms`、`--timeout-ms`付き）です |
| `browser mouse scroll/move` | 座標での生マウス入力です |
| `browser tab list/close/switch` | セッション内のタブ管理です |
| `browser network start/stop/list/tail/detail` | リクエスト／レスポンスのキャプチャです |
| `browser console start/stop/list/tail` | コンソール＋JSエラー取得です |
| `browser login <url>` | ヘッドフルログインでブロックします（`--profile`、`--done`、`--success-pattern`） |
| `browser captcha` | 検出／解決します（none\|2captcha\|capsolver\|manual、`--detect-only`） |
| `browser close [--all]` | 1セッションまたは全体を閉じます |

## 環境変数

| 変数 | 用途 |
|---|---|
| `OMNISCOUT_JSON=1` | すべてのコマンドでJSON出力を強制します |
| `OMNISCOUT_DAEMON_AUTO_START=0` | daemonを自動起動しません |
| `OMNISCOUT_DAEMON_PORT` | daemonポートを上書きします（デフォルト7720） |
| `OMNISCOUT_DATA_DIR` | データディレクトリを上書きします |
| `OMNISCOUT_BROWSER` | ブラウザIDです（設定を上書きします） |
| `OMNISCOUT_EMBED_LOCAL_ONLY=0` | 実行時のHugging Face取得を許可します |
| `TWOCAPTCHA_API_KEY` / `CAPTCHA_API_KEY` | CAPTCHAソルバーのキーです |

設定キーとデータ配置の完全な一覧は[設定](/docs/configuration)をご覧ください。
