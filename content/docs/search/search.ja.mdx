## どのコマンドが必要ですか？

| コマンド | 戻り値 | 使用場面 |
|---|---|---|
| `answer` | 引用付きの統合回答です | リンク一覧ではなく事実が必要な場合（推奨）です |
| `search` | ランク付きURLヒットです | 自分で開く・クロール・引用するリンクが必要な場合です |
| `map` | サイト上の読みやすいURL群です | ドメイン全体を探索したい場合です |
| `warmup` | なし（モデルを事前読み込みします） | 一括呼び出しの前に初回遅延を削減したい場合です |

## answer — 直接Q&A

```bash
omniscout answer "Who is the prime minister of India?"
omniscout answer "latest stable Rust version" --depth balanced
```

### Depthモード

`--depth`は回答の裏側でどれだけ取得を行うかを制御します：

| Depth | 動作 | 速度 |
|---|---|---|
| `fast` | 検索スニペットのみから回答します | 最速です |
| `balanced` | インデックス＋上位出典のWeb取得を行います | 中程度です |
| `deep` | 上位出典をクロールしてから回答します | 最も遅いですが徹底的です |
| `auto`（デフォルト） | 質問に応じて自動選択します | 状況により異なります |

### 回答エンジン

回答を統合するエンジンは2種類あります。デフォルトは設定（`omniscout settings engines`）から取得しますが、呼び出しごとに上書きできます：

```bash
omniscout answer "..." --probe      # Probe Zero Mini (local LLM)
omniscout answer "..." --classic    # Classic extractive engine
omniscout answer "..." --probe-pro  # Probe Pro: structured-claim pipeline with crawl + verify
omniscout answer "..." --no-llm     # extractive fallback only, no LLM at all
```

検討する検索結果数は`--limit/-n`で変更します（デフォルト10）。`--data`を付けると出典、タイミング、検索診断を出力に含めます。

## search — ランク付きWebヒット

```bash
omniscout search "vector database benchmarks 2026"
omniscout search "AI agents 2026" --limit 5
```

結果はWebから取得し、**sentence-transformers埋め込みモデルでローカルにリランク**します。そのためクエリと意味的に最も近いヒットが上位に来ます — LLM呼び出しは不要です。呼び出しごとに`--no-rerank`でリランクを無効化できます。`search`にはバンドルUIもあります：

```bash
omniscout search ui   # open the local search UI (SearXNG at 127.0.0.1:8888)
```

### 検索ソース

呼び出しごとに`--source`（`ddg | index | memory | hybrid`）でソースを選びます：

```bash
omniscout search "query" --source ddg
omniscout search "query" --source memory   # your remembered pages only
```

デフォルトソースは`config.toml`（`default_source`：`searxng | ddg | wikipedia | web`）にあります。`--from/--to`（YYYY-MM-DD）と`--country`でクエリに時期・地域のヒントを付けられます。

デフォルトの変更は[設定](/docs/configuration)をご覧ください。

## map — サイトのURLをクロールします

```bash
omniscout map stripe.com
```

`map`はドメインのURLマップを生成します — サイトの内容を把握してから対象を絞った`extract`や`research`を実行したい場合に便利です。

## warmup — モデルを事前読み込みします

```bash
omniscout warmup
```

埋め込みモデルと回答モデルをdaemonに事前読み込みします。インストール直後（またはデモ前）に一度実行すると、初回呼び出し時にモデルのダウンロードとウォームアップを待たずに済み、高速になります。

## エージェント向けヒント

- 引用付きの事実が必要な場合は`search`より`answer`を優先します。
- `--json`出力を`jq`にパイプしてフィールドを抽出します：`omniscout search "topic" | jq '.hits[] | {title, url}'`。
- 結果が期待と違う場合は、情報がないと決めつける前に、クエリを具体化するか別の`--source`を試します。
