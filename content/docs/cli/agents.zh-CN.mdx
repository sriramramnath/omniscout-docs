OmniScout 专为 AI 智能体驱动而打造。设置方法如下。

## 1. 安装

```bash
pip install omniscout
omniscout install --skill
```

`--skill` 标志会将说明文件复制到智能体的技能目录：

| 智能体 | 位置 |
|---|---|
| Claude Code | `~/.claude/skills/scout/SKILL.md` |
| Cursor | `~/.cursor/skills-cursor/scout/SKILL.md` |
| Codex | `~/.codex/skills/scout/SKILL.md` |

智能体将在下一次会话中自动加载。

## 2. 启动 daemon

```bash
omniscout daemon start
```

## 3. 粘贴提示词

### 研究一个问题

```text
使用 OmniScout 研究“2026 年开源浏览器智能体现状”，并总结前 5 段最相关的内容及其来源 URL。
```

### 导航并点击

```text
使用 OmniScout 打开 https://news.ycombinator.com，快照可交互元素，点击热度最高的帖子，并将结果截图保存到 /tmp/hn-top.png。
```

### 登录一次并复用

```text
运行 `omniscout browser login https://github.com --profile work`，暂停等我完成认证，然后用该配置文件截取我的通知页面。
```

### 构建知识图谱

```text
使用 OmniScout 为“Cursor”构建知识图谱。运行 `omniscout graph "Cursor" --json --data`，展示树状结构并引用来源。
```

### 填写表单

```text
使用 OmniScout 打开 https://duckduckgo.com，在搜索框中填写“local-first AI agents”，按回车，等待结果，并列出前 5 个结果。
```

### 捕获网络流量

```text
使用 OmniScout 打开 Vercel 定价页，在滚动时捕获网络流量，然后列出匹配 stripe|payment|checkout 的请求。
```

## 给智能体的建议

- 开始时设置 `OMNISCOUT_JSON=1` 以获得结构化输出
- 使用 `omniscout browser snapshot --refs-only` 查找元素，然后按 `@eN` 引用点击
- 每次 `navigate` 后重新快照——引用会过期
- 完成后使用 `omniscout browser close --all` 关闭会话
