常见任务的可复制配方。背后的概念：[快速上手](/docs/cli/quickstart)、[浏览器自动化](/docs/cli/browser)、[提取](/docs/cli/extraction)。

## 快速参考

```bash
omniscout daemon start                              # 1. start the daemon
omniscout browser navigate https://example.com      # 2. drive the browser
omniscout browser snapshot --refs-only              # 3. find @eN refs
omniscout browser click '@e3'                       # 4. act on them
omniscout browser screenshot --out /tmp/out.png     # 5. capture state
omniscout browser close --all                       # 6. clean up
```

## 搜索与问答

```bash
# One-line factual answer (preferred for facts)
omniscout answer "who is the prime minister of india"
omniscout answer "what is the capital of france"
omniscout answer "latest stable Rust version" --depth deep --data

# Web search with ranked hits
omniscout search "AI agents 2026" --limit 5
omniscout search "query" --source memory   # your remembered pages only
```

## 从页面提取内容

```bash
omniscout extract https://example.com > /tmp/page.md
omniscout extract https://stripe.com/pricing --format structured --fields pricing
omniscout extract -q "SpaceX founder" --format structured --fields founder
omniscout extract https://example.com --depth 2 --out /tmp/site.md
```

## 先读后动

```bash

```

## 填写表单

```bash
omniscout browser navigate https://duckduckgo.com
omniscout browser snapshot --refs-only
omniscout browser fill '@e2' "local-first AI agents"
omniscout browser key Enter
omniscout browser wait text "results"
omniscout browser get text | head -20
```

从 snapshot 输出中找到搜索框的 ref — 不要猜 `@e` 编号。（`fill` 替换；`type` 追加；`paste` 在光标处插入。）

## 正确等待

```bash
omniscout browser navigate https://example.com/app
omniscout browser wait networkidle
omniscout browser wait text "Dashboard"
omniscout browser snapshot --refs-only
```

## 登录并复用 profile

```bash
# Terminal A: opens browser, blocks
omniscout browser login https://github.com/login --profile work

# Terminal B (after you log in):
omniscout browser login --done

# Now reuse the profile
omniscout browser navigate https://github.com/notifications --profile work
omniscout browser screenshot --out /tmp/notifs.png
```

## 录制可复用的 macro

```bash

omniscout record stop signup-flow
omniscout macro run signup-flow
```

## Python 与 shell 集成

```bash
export OMNISCOUT_JSON=1

omniscout search "topic"          | jq '.hits[] | {title, url}'
omniscout browser snapshot        | jq '.refs[] | select(.role == "button")'
omniscout extract https://...     | jq '{title, word_count}'
omniscout research "topic"        | jq '.passages[0:3]'
```

```python
import json, subprocess

def scout(*args):
    out = subprocess.run(
        ["omniscout", "--json", *args],
        capture_output=True, text=True, check=True,
    )
    return json.loads(out.stdout)

hits = scout("search", "local-first AI agents")["hits"]
print([h["url"] for h in hits[:3]])
```
