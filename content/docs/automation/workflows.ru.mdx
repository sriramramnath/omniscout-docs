## Запись и повтор макросов

Превратите интерактивный запуск в переиспользуемый скрипт:

```bash
omniscout record start --name my_macro
omniscout browser navigate https://example.com
omniscout browser snapshot --refs-only
omniscout record stop my_macro

omniscout macro list
omniscout macro run my_macro
```

`record start/stop` захватывает успешные действия daemon для сессии в именованный macro; `macro run` переигрывает его через daemon. Для низкоуровневого повтора сырой истории действий используйте `omniscout replay …` и `omniscout daemon replay`.

## Непрерывность workflow

Многошаговые процессы хранят состояние непрерывности, которое можно inspect и export:

```bash
omniscout context            # show current workflow state
omniscout reset              # reset it and start fresh
omniscout workflow export    # export steps as JSON (share or persist a process)
```

`auto` маршрутизирует однострочный запрос к лучшей команде, когда не хочется выбирать:

```bash
omniscout auto "latest AI news"
```

Топ-уровневые `open` и `snapshot` — это шорткаты в браузер сессии по умолчанию:

```bash
omniscout open https://example.com
omniscout open 3              # open the 3rd result of the last search
omniscout snapshot --refs-only
```

## Отслеживание изменений URL

```bash
omniscout monitor monitor https://example.com/pricing
```

`monitor` непрерывно извлекает URL и выдаёт JSON-строку при каждом изменении контента — направьте её в `jq` или скрипт для отслеживания цен, алёртов changelog и status-страниц.

## Задачи обхода

```bash
omniscout crawl ...           # run and inspect local crawl jobs
omniscout extract-jobs ...    # inspect background extract jobs
omniscout index ...           # manage the local search index
```

Обходы поддерживают bulk-режимы [Извлечения](/docs/search/extraction) (экспорт сайта через `--out`, режим `--query`): запускайте их в фоне и inspect результаты вместо блокировки одного шелла.

## Советы для агентов

- Запишите один раз, выполняйте `macro run` вечно — макросы самый дешёвый способ сделать хрупкие многошаговые процессы детерминированными.
- `workflow export` даёт JSON-артефакт для приложения к тикетам, PR или eval-датасетам.
- При отладке предпочитайте `daemon trace` повторному запуску: последние 10k действий уже записаны.
