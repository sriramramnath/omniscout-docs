---
title: Использование и оплата
description: Оплата по использованию OmniScout Cloud, лимиты расходов и metered-биллинг Stripe.
---

OmniScout Cloud использует **только оплату по использованию**. Нет уровней подписки, включённых месячных часов или лимитов API по тарифам.

## Формула цены

```
customer_charge = actual_infrastructure_cost × 1.30
```

Это **наценка 30% на себестоимость** (стоимость + 30%), а не 30% валовой маржи.

## Оплачиваемые ресурсы

| Ресурс | Учёт | Событие счётчика Stripe |
|---|---|---|
| Рантайм компьютера | Секунды от готовности сессии → уничтожения | `computer_runtime_seconds` |
| Рантайм браузера | Секунды от готовности сессии → уничтожения | `browser_runtime_seconds` |
| Поиск | За запрос `POST /v0/search` | `search_requests` |
| Ответы | За запрос `POST /v0/answer` | `answer_requests` |

Вызовы API, такие как `GET /v0/sessions/{id}` и `POST /v0/sessions/{id}/actions`, **не** учитываются как использование API. Они безлимитны с учётом защиты от злоупотреблений, лимитов параллельности, TTL сессий и лимитов расходов.

## Двухуровневый биллинг

| Уровень | Роль |
|---|---|
| **Convex-реестр использования** | Аудит, оценки стоимости в реальном времени, контроль лимитов расходов |
| **Stripe Billing** | Способ оплаты, metered-использование, счета, Customer Portal |

## GET /v0/usage

Возвращает использование за текущий период, оценочную стоимость, активные сессии, лимиты расходов и статус оплаты.

```json
{
  "period": "2026-09",
  "usage": {
    "computer_runtime_seconds": 3600,
    "browser_runtime_seconds": 1200,
    "search_count": 42,
    "answer_count": 8
  },
  "costs": {
    "underlying_cost_usd": 12.5,
    "markup_multiplier": 1.3,
    "estimated_charge_usd": 16.25
  },
  "spending_limit_usd": 100,
  "spending_limit_remaining_usd": 83.75,
  "billing_status": "active"
}
```

## Защита расходов

При превышении месячного лимита расходов оплачиваемые операции возвращают `402` с `spending_limit_exceeded`. Аккаунты со статусом оплаты `past_due` могут быть заблокированы до решения вопроса с оплатой.

## Дашборд

Просматривайте использование и оценочную стоимость на странице [биллинга дашборда](https://api.omniscout.xyz/dashboard/billing). Откройте Stripe Customer Portal с этой страницы, чтобы управлять способами оплаты и счетами.

## Настройка

Операторы настраивают счётчики Stripe, webhook и тарифы себестоимости согласно `cloud/SETUP.md` в репозитории.
