OmniScout Cloud uses **usage-based pricing only**. You pay for what you use — there are no subscriptions or plans to pick.

## Why usage-based?

You get the full API — search, answers, and remote browser sessions — without committing to a monthly plan. Light use costs little, and heavy use scales with what you actually run.

## What you pay for

| What you use | How it is counted |
|---|---|
| Computer sessions | Seconds your session is running |
| Browser sessions | Seconds your session is running |
| Search | Per search request |
| Answer | Per answer request |

Checking session status or sending commands to an open session is not billed separately.

## Check your usage

See your current usage and estimated charges any time:

```json
{
  "period": "2026-09",
  "usage": {
    "computer_runtime_seconds": 3600,
    "browser_runtime_seconds": 1200,
    "search_count": 42,
    "answer_count": 8
  },
  "costs": {
    "estimated_charge_usd": 16.25
  },
  "spending_limit_usd": 100,
  "spending_limit_remaining_usd": 83.75,
  "billing_status": "active"
}
```

- API: `GET /v0/usage` with your API key
- Dashboard: [Usage](https://api.omniscout.xyz/dashboard/usage) and [Billing](https://api.omniscout.xyz/dashboard/billing)

## Spending protection

Set a monthly spending cap and OmniScout stops billable use before you overspend. When the cap is reached, requests return a `402` error with `spending_limit_exceeded` — raise the cap to continue.

If a payment fails, new billable use may be paused until billing is up to date.

## Manage payment

View usage and estimated charges on the [dashboard billing](https://api.omniscout.xyz/dashboard/billing) page. Open the Customer Portal from that page to manage payment methods and invoices.
